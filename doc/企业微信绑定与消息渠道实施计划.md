# 企业微信绑定与消息渠道实施计划

**目标：** 为教师和学生增加企业微信 UserId 绑定、企业微信消息渠道投递、免打扰时间段和管理员解绑能力。

**架构：** 企业微信 OAuth 回调只生成短期绑定票据，当前登录账号确认后写入现有 `user_wechat` 表。消息服务保留站内消息落库，按模板或手动发送渠道生成企业微信投递任务；企业微信驱动从 UserId 绑定和通知偏好筛选接收人，按时间段计算延迟后由现有 Redis 队列发送。管理员角色不受绑定门槛限制，但可在用户详情中解除绑定。

**技术栈：** PHP 8.4、Webman、MySQL、Redis、企业微信自建应用 OAuth 和 `message/send` 接口、Vue 3 PC/H5。

## 全局约束

- 使用现有学校配置、学校上下文、JWT、Redis 和 RedisQueue。
- 企业微信身份使用自建应用 `UserId`；不把 Secret、access_token 或 OAuth code 返回给前端。
- 教师和学生未绑定时不能进入业务页面；管理员角色跳过绑定门槛。
- 企业微信通知默认全天；免打扰时间外消息顺延，不丢弃站内消息。
- 企业微信投递失败不回滚站内消息，写入渠道日志并依赖现有队列重试。
- 不新增 RabbitMQ/RocketMQ；队列任务只传学校库、消息和账号标识，不传大文件。
- 不生成测试文件；只做 PHP 语法、前端构建、路由和无凭证接口核验。

**接口：**
- `GET /api/wechat/binding-status`：返回当前账号绑定状态、是否必须绑定、OAuth URL。
- `GET /api/wechat/oauth/start`：生成 state 并重定向企业微信 OAuth。
- `GET /api/wechat/oauth/callback`：交换 UserId，写入短期 Redis 票据并重定向前端。
- `POST /api/wechat/bind`：当前登录教师/学生消费票据并写入 UserId。
- `POST /api/wechat/unbind`：当前账号解除自身绑定。
- `WechatBindingService::bindingStatus()`、`beginOAuth()`、`finishOAuth()`、`bindTicket()`、`unbindCurrent()`。

**规则：**
- state 只允许一次使用，保存学校库、当前账号（可为 0）、回跳路径和随机值，TTL 600 秒。
- callback 不要求 JWT；如果 state 带当前账号则绑定票据限定该账号，否则票据等待登录后的账号确认。
- `getuserinfo` 成功但返回 `UserId` 为空时拒绝绑定；UserId 已绑定其他用户时拒绝。
- 绑定前检查当前账号角色为 teacher/student；管理员返回跳过状态。
- 登录和刷新 session 返回 `wechat_binding` 状态，PC/H5 初次加载据此显示阻断弹窗。
- 绑定票据只保存 UserId、姓名和学校库，不保存 access_token。

- 修改：`server/database/init.php`
- 创建：`server/database/updates/20260922-wechat-message.sql`

**接口：**
- `WechatClient::sendTextMessage()`：调用 `/cgi-bin/message/send`。
- `WechatMessageService::enqueue()`：按账号绑定、通知开关和时间段生成队列任务。
- `WechatMessageService::send()`：获取 access_token、发送文本、写渠道日志。
- `user_notify_setting` 增加 `quiet_start`、`quiet_end`，默认 `00:00` 到 `24:00`。

**规则：**
- 模板 `channels` 默认 `['internal']`；兼容现有模板数据。
- 当前发送消息可传 `channels`，未传时使用模板 channels；手动消息默认站内消息。
- 每条消息始终先写站内目标；企业微信仅为额外渠道。
- 仅发送给 `user_wechat` 已绑定且 `wechat` 通知开启的账号。
- 免打扰时间支持跨午夜；落在禁用区间的任务用 RedisQueue delay 顺延到下一个允许时间。
- 企业微信发送失败抛出异常，由队列重试；渠道日志状态为 pending/sent/failed，未绑定为 skipped。
- access_token 用 Redis 按学校库缓存，TTL 由企业微信返回值减 60 秒。
