# 企业微信绑定与消息渠道实施计划

- 企业微信内老师、学生通过网页授权读取 UserId，确认绑定后继续；管理员跳过，普通浏览器不强制绑定。
- OAuth state 关联学校、浏览器、登录账号与企业配置；HttpOnly Cookie 保存不透明身份票据，确认绑定票据一次性使用。
- 复用 user_wechat 一对一约束，禁止覆盖既有不同绑定；管理员在用户详情解除绑定，操作日志保留解绑记录。
- 消息中心与两处模板编辑支持 internal/wechat 渠道，始终保留站内消息；模板未指定新渠道时保留原配置。
- 企业微信待发送日志与消息事务共同提交。后台分发进程将到期记录写入 RedisQueue，消费者核对接收人、绑定、通知偏好与允许时段，记录结果并重试暂时错误。
- 个人通知接收时段默认 00:00 至 24:00，支持跨午夜；时间段外顺延，站内消息即时可见。
- 数据结构同步到初始化流程和可重复执行的学校库升级 SQL；PC/H5 构建产物一并发布。
- 完成 PHP 语法检查、PC/H5 构建、无凭证路由核验及独立代码审查后提交推送。

接口与部署说明见《企业微信绑定与消息渠道.md》。
