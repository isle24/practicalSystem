# 社会实践管理模块实施计划

> 实施时逐项更新勾选状态。根据项目规则不创建测试文件，仅执行语法、数据库初始化、构建、接口和页面验证。

**目标：** 根据已确认的社会实践流程，建设独立的集中实践与分散实践管理模块。

**架构：** 新增 `SocialPracticeController`、`SocialPracticeService` 和 `SocialPracticeRecord`，所有查询封装在 Model。模块复用学校库上下文、数据范围、Redis 锁、审核意见、文件、消息、待办和通用前端组件，不并入 `PracticeService`。

**技术栈：** PHP 8.4、Webman、Illuminate Database、MySQL、Redis、Vue 3、Element Plus、Vant。

## 全局约束

- 所有学校业务数据位于当前学校业务库，不增加学校字段。
- 使用 Webman 默认路由，不修改框架和路由组件。
- Controller 只负责请求、Service 调用和响应；Service 不直接拼接查询。
- 统一按年级管理，不增加学期、学年或毕业届次字段。
- 流程提交、审核、退回、重新提交和通过后修改必须写入 recording 和审核意见。
- 前端提交按钮需防重复点击，后端写操作使用事务、行锁和 Redis 业务锁。
- 前端构建产物同步到 `server/public/pc` 和 `server/public/h5`。
