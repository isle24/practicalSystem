# 年级届次、基地导入与教师同步改造实施计划

> 执行时按任务顺序推进，每个任务完成后独立提交。不得修改 Webman 框架代码或增加自定义路由。

**目标：** 实现独立年级与毕业届次、可维护实习类别、实习基地 Excel 导入、校内教师双向同步协议，以及 PC 公共弹窗、列表字段、侧栏和 Tab 交互。

**架构：** 学校业务库通过 `server/database/init.php` 幂等升级。Controller 只负责请求和响应，查询与写入集中在 Model，字段校验和事务编排集中在 Service。PC 复用公共弹窗、列表、侧栏和 Tab 组件，H5 只调整受时间维度影响的显示和请求字段。

**技术栈：** PHP 8.4、Webman、MySQL、Redis、PhpSpreadsheet、Vue 3、Element Plus、Lucide。

## 全局约束

- 后端代码放在 `server`，PC 前端放在 `fontend/pc`，移动端放在 `fontend/h5`。
- 使用 Webman 默认路由，不修改框架代码。
- Controller 不直接编写数据库查询。
- 所有查询和写入由 Model 方法封装。
- 不创建额外的验证代码或数据生成器。
- 业务弹窗、列表、侧栏和 Tab 优先复用公共组件。
- 完成后编译 PC/H5，并同步到 `server/public/pc`、`server/public/h5`。
