# H5 页面转场与玻璃导航实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 将 H5 页面切换改为无空档的 iOS 式分层转场，并增强顶部、底部导航的常驻玻璃效果。

**架构：** `AppPageTransition` 只负责转场生命周期和页面容器；具体节奏统一维护在 `styles/motion.css`。导航玻璃样式继续由现有 H5 全局样式维护，不向业务页面增加视觉逻辑。

**技术栈：** Vue 3 Transition、CSS transform/opacity、backdrop-filter、Vite。

## 全局约束

- 不修改业务接口、权限、导航历史和系统返回逻辑。
- 不增加手势、动画依赖或状态管理依赖。
- 不新增测试文件，使用生产构建和 Playwright 临时巡检命令验证。
- 生产构建产物写入 `server/public/h5`。

---

### 任务 1：无空档页面转场

**文件：**

- 修改：`fontend/h5/src/components/ui/AppPageTransition.vue`
- 修改：`fontend/h5/src/styles/motion.css`

**接口：**

- 输入：`pageKey: string | number`、`direction: 'tab' | 'forward' | 'back'`
- 输出：保持现有默认插槽和三种转场名称，不改变调用方接口。

- [ ] 移除 Vue Transition 的 `mode="out-in"`，让进入和离开同时执行。
- [ ] 为转场容器增加横向裁剪和隔离上下文。
- [ ] 让离场页面在动画阶段绝对定位，避免双页面同时占据文档流。
- [ ] 主 Tab 使用 `200ms` 淡入、轻缩放和 `4px` 上浮。
- [ ] 二级进入使用 `240ms`、`12px` 入场和 `-6px` 退场。
- [ ] 二级返回使用 `220ms`、反向短位移。
- [ ] 保留 `prefers-reduced-motion` 降级。

### 任务 2：顶部与底部玻璃导航

**文件：**

- 修改：`fontend/h5/src/styles/tokens.css`
- 修改：`fontend/h5/src/styles.css`

**接口：**

- 新增视觉变量：`--app-glass-bg`、`--app-glass-bg-fallback`、`--app-glass-line`、`--app-glass-shadow`。
- 保持 `.mobile-app-header`、`.mobile-bottom-nav` 现有类名和层级。

- [ ] 增加玻璃背景、边框和阴影变量。
- [ ] 顶部导航使用 `blur(20px) saturate(145%)` 与浅色下边框。
- [ ] 底部导航使用相同模糊参数、浅色上边框和轻微向上阴影。
- [ ] 同时声明 `-webkit-backdrop-filter`。
- [ ] 使用 `@supports not` 提供高不透明度背景降级。
- [ ] 减少动态效果模式下禁用导航背景过渡。
