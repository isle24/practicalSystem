# 前端视觉改造实施计划

**目标：** 按 `20-前端视觉与交互规范.md` 完成 PC 端 Fluent 桌面与全屏 Launchpad，并将 H5 端改造成原生 App 信息架构。

**实现方式：** 保留现有 Vue 3、Element Plus、Vant、Lucide 和 API 调用。优先扩展现有公共组件，将桌面外壳、启动台、窗口和移动导航从业务页面中分离；业务模块继续消费现有状态和接口。

**技术栈：** Vue 3、Vite、Element Plus、Vant 4、Lucide。

## 全局约束

- 不修改 Webman 框架、默认路由和第三方组件源码。
- 不修改业务状态机、权限范围和 API 协议。
- PC 源码位于 `fontend/pc`，H5 源码位于 `fontend/h5`。
- 构建产物分别同步到 `server/public/pc` 和 `server/public/h5`。
- 公共组件只提供底层布局、状态和交互能力，不写业务判断。
- 不新增前端依赖。
