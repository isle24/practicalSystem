# PC 桌面模块聚合与自适应设计

## 模块关系

桌面和启动台只显示聚合入口，聚合入口内复用现有业务模块：

- 数据管理：统计报表、用户管理、年级管理、学院管理、专业管理、班级管理、基地管理、测试数据清理。
- 日志审计：操作日志、导出任务。
- 资源中心：文件管理、文档中心、模板库、收藏夹。
- 系统配置、个人设置保持独立。
- 实习管理、实验实训管理保持独立并作为默认固定桌面模块。

原业务模块继续保留独立窗口、接口、权限和哈希地址。聚合入口只负责展示当前角色可访问的子模块并调用原窗口打开函数。

## 兼容规则

- 历史桌面快捷方式中的子模块 ID 在前端归并为对应聚合入口。
- 全局搜索仍可搜索并直接打开原业务模块。
- 历史 `#module`、`#panel` 链接继续按原模块 ID 打开。
- 菜单配置产生的模块继续参与权限合并，不复制菜单和业务状态。

## 桌面布局

桌面网格通过 `ResizeObserver` 读取工作区实际宽高。布局在保持原始图标尺寸优先的前提下，计算可容纳全部快捷方式的行列数；空间不足时同比缩小图标容器和单元格，避免固定行高造成底部裁切。

## 细节调整

- 消息未读角标完全位于任务栏按钮内部，不进入横向滚动容器的裁切区域。
- 实习总览指标统一为图标、名称、数量的单行顺序。
