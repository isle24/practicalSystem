# 消息服务设计

## 1. 数据模型

```
message（消息主表）
  - id
  - title, content
  - type: system / alert / audit / todo / result
  - sender_id（系统=0，或具体发送人）
  - level: normal / important / urgent
  - status
  - created_at, updated_at, deleted_at

message_target（消息接收表）
  - id, message_id, account_id
  - is_read, read_at
  - created_at, updated_at, deleted_at

message_template（消息模板）
  - id, code（唯一标识）
  - title_tpl, content_tpl
  - channels（JSON 数组，如 ["internal", "wechat"]）
  - status
  - created_at, updated_at, deleted_at

message_channel_log（渠道投递日志）
  - id, message_id, account_id
  - channel: internal / wechat / sms / ...
  - status: pending / sent / failed
  - error_message
  - sent_at
  - created_at, updated_at, deleted_at
```

模板变量支持：`{student_name}`、`{apply_time}`、`{result}` 等。

## 2. 渠道驱动架构

每个渠道独立实现 ChannelDriver 接口，新增渠道只需新增驱动类，不修改现有逻辑。

```
app/server/message/
├── MessageService.php          # 消息服务入口
├── drivers/
│   ├── ChannelDriver.php       # 驱动接口
│   ├── InternalDriver.php      # 站内消息
│   ├── WechatDriver.php        # 企业微信推送
│   ├── SmsDriver.php           # 短信（预留）
│   └── ...                     # 后续扩展
```

### ChannelDriver 接口

```php
interface ChannelDriver
{
    public function send(int $messageId, array $accountIds, string $content): array;
    // 返回 ['account_id' => 'sent'|'failed', ...]
}
```

## 3. 发送流程

```
业务触发（如审核通过）
  → MessageService::send('internship_approved', $targetAccountIds, $vars)
  → 查询模板 → 替换变量 → 写入 message + message_target
  → 遍历模板 channels，逐个调用驱动投递：
      ├── internal → InternalDriver::send()  → 写 message_channel_log
      ├── wechat   → WechatDriver::send()    → 入 Redis 队列 → 异步投递
      └── sms      → SmsDriver::send()       → 入 Redis 队列 → 调用三方 API
  → 每个渠道独立记录投递状态到 message_channel_log
  → 发送失败 → 自动重试 3 次 → 仍失败标记 failed
```

- internal 驱动同步写入，立即可见
- wechat/sms 等外部渠道入 Redis 队列异步投递，不阻塞接口响应
- message_channel_log 记录每个账号在每个渠道的投递结果，便于排查

### H5 端

- 消息详情
- 全部已读

- 消息详情
- 全部已读

| 场景 | 类型 | 渠道 |
|---|---|---|
| 实习申请提交 | todo | internal + wechat |
| 审核通过/退回 | result | internal + wechat |
| 日志被点评 | result | internal + wechat |
| 报告被评阅 | result | internal + wechat |
| 签到异常提醒 | alert | internal + wechat |
| 报告截止提醒 | todo | internal + wechat |
| 导出任务完成 | result | internal |
| 系统通知 | system | internal |
