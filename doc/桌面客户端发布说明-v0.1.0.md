# 实践管理系统客户端 v0.1.0

客户端内置现有 Vue PC 界面，使用学校服务器的接口、JWT 登录和业务权限。首次启动填写学校域名，例如 `sx.2iwm.com`，随后使用现有学校账号登录；可在应用菜单“连接设置”中切换学校。

## 选择安装包

| 设备 | Assets 中的文件 | 安装方式 |
| --- | --- | --- |
| Mac，Intel 或 Apple Silicon | `Practical-System_0.1.0_macos-universal.dmg` | 推荐通用包；打开后拖入“应用程序”，需要 macOS 12 或更新版本 |
| Mac，仅 Apple Silicon | `Practical-System_0.1.0_macos-arm64.dmg` | 体积更小；Intel Mac 请使用通用包 |
| Windows x64 | `Practical-System_0.1.0_windows-x64-setup.exe` | 双击安装；缺少 WebView2 时安装器需要联网获取运行时 |
| Linux x64，Debian / Ubuntu | `Practical-System_0.1.0_linux-amd64.deb` | 使用系统软件安装器或 `sudo apt install ./Practical-System_0.1.0_linux-amd64.deb` |
| Linux x64，AppImage | `Practical-System_0.1.0_linux-amd64.AppImage` | 添加可执行权限后运行，设备需要 FUSE 运行条件 |
| 校验文件 | `SHA256SUMS.txt` | 包含上述五个安装包的 SHA256 |

下载 Assets 中的安装包即可。“Source code (zip)”和“Source code (tar.gz)”为源码，不是安装程序。仓库为私有仓库，下载需要登录具有仓库访问权限的 GitHub 账号。

## 使用与平台限制

- 学校服务器需提供有效 HTTPS；HTTP 仅支持本机地址 `localhost`、`127.0.0.1`、`[::1]`。可输入端口，不需要填写 `/pc/index.html`。
- 支持保存学校地址、原生窗口调整、附件预览、系统另存为、外部链接在默认浏览器打开。JWT 会话仅保存在运行内存中，关闭学校窗口或退出客户端后需要重新登录。
- 客户端内置 PC 页面，界面更新需要安装新版客户端；首版没有自动更新和离线业务提交。
- 当前未配置 Apple Developer 签名、公证或 Windows 代码签名证书。macOS Gatekeeper、Windows SmartScreen 可能显示发布者验证提示，不能视为已签名的正式分发包。
- Mac Apple Silicon 已核对学校连接、教师及学生登录、PDF 预览、Word 下载和另存为。Windows/Linux 已完成构建，尚未实机验收；Intel Mac 启动、上传和实际打印尚未完成实机核对。
- 本版不包含鸿蒙 NEXT 客户端。
