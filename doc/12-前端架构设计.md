# 前端架构设计

## 1. 技术选型

| 端 | 框架 | UI 库 | 说明 |
|---|---|---|---|
| H5 移动端 | Vue 3 | Vant 4 | 企业微信内嵌 / 手机浏览器 |
| PC 管理端 | Vue 3 | Element Plus | 全角色（管理员/教师/学生） |
| 图表 | ECharts 5 | — | 统计报表可视化 |
| 状态管理 | Pinia | — | 两端共用 |
| 构建工具 | Vite | — | 两端共用 |
| 编译输出 | H5 → server/public/h5/ | PC → server/public/pc/ | — |

默认访问 `GET /` 根据浏览器 UA 自动跳转：移动端/平板 → `/h5/`，桌面端 → `/pc/`。同一域名、同一浏览器登录态下，H5 与 PC 共用 httpOnly Cookie 中的 JWT；跨设备访问需要重新登录或重新完成企业微信认证。

### H5 端核心功能

- 企业微信 JSSDK 封装（定位、扫码、拍照）
- v-permission 指令（按钮权限）
- v-prevent-duplicate 指令（防重复提交）
- 深色模式 + 字体三档调节
- 响应式适配（手机/平板）
- 顶部常驻消息入口，角色与账号信息只在首页和“我的”显示

**H5"我的"页面结构：**

```

└── 关于              版本号、用户协议、隐私政策
```

### 3.4 主题系统

系统采用**主题包**设计：每个主题是一组预设（壁纸 + 主题色 + 图标风格 + 深浅模式），一键切换全套视觉效果，后续新增主题只需增加一条配置记录。

**主题表：**

```
theme_preset（主题预设，系统初始化时写入，管理员可增删）
  - id
  - code（唯一标识，如 "ocean_blue"）
  - name（主题名称，如"海洋蓝"）
  - wallpaper（壁纸 URL 或预设 ID）
  - primary_color（主题色 HEX，如 #1a73e8）
  - secondary_color（辅助色 HEX）
  - icon_style: filled / outlined / dualtone（图标风格）
  - dark_mode_wallpaper（深色模式壁纸，可选）
  - dark_primary_color（深色模式主题色，可选，不填=自动生成）
  - sort（排序）
  - is_default: yes / no（是否默认主题）
  - flag: on / off
  - created_at, updated_at, deleted_at
```

**预置主题包：**

| code | name | 壁纸 | 主题色 | 图标风格 |
|---|---|---|---|---|
| ocean_blue | 海洋蓝 | 蓝色几何抽象 | #1a73e8 | filled |
| forest_green | 森林绿 | 绿色自然风景 | #0d9488 | outlined |
| sunset_orange | 霞光橙 | 暖色渐变 | #f59e0b | dualtone |
| galaxy_purple | 极客紫 | 深空星云 | #7c3aed | filled |
| classic_white | 经典白 | 纯白极简 | #3b82f6 | outlined |
| midnight_dark | 午夜暗 | 纯黑质感 | #6366f1 | dualtone |

每个主题包自动包含深色模式变体（壁纸和主题色的暗色版本），切换深浅模式时主题包内自动切换对应变体。

**用户配置（简化）：**

```
user_desktop_config
  - id
  - account_id（唯一约束）
  - theme_code（当前使用的主题，关联 theme_preset.code，默认 "ocean_blue"）
  - dark_mode: auto / light / dark（默认 auto=跟随系统）
  - icon_size: small / medium / large（默认 medium）
  - taskbar_auto_hide: true / false（默认 false）
  - created_at, updated_at
```

**后续扩展：** 新增主题只需 `INSERT INTO theme_preset` 一行 + 准备壁纸图片，零代码改动：

```sql
-- 新增"樱花粉"主题
INSERT INTO theme_preset (code, name, wallpaper, primary_color, icon_style, sort)
VALUES ('sakura_pink', '樱花粉', '/pc/wallpapers/sakura.jpg', '#ec4899', 'filled', 7);
```

**CSS 变量注入：** 切换主题时更新 `:root` 变量，全页面即时生效无需刷新：

```css
[data-theme="ocean_blue"] {
  --primary: #1a73e8; --primary-hover: #1557b0;
  --taskbar-bg: #ffffff; --desktop-bg: url(/pc/wallpapers/ocean.jpg);
  --icon-style: filled;
}
[data-theme="ocean_blue"][data-dark="true"] {
  --primary: #4da3ff; --taskbar-bg: #0f1923;
  --desktop-bg: url(/pc/wallpapers/ocean_dark.jpg);
}
```

### 3.5 Window.vue 核心属性

```typescript
interface WindowState {
  id: string;           // 窗口唯一标识
  title: string;        // 标题
  icon: string;         // 图标
  component: string;    // 对应的 Vue 组件名
  props: object;        // 传给组件的参数
  x: number; y: number; // 位置
  width: number; height: number;  // 尺寸
  minimized: boolean;   // 是否最小化
  maximized: boolean;   // 是否最大化
  zIndex: number;       // 层级
}
```

窗口打开时记录到 WindowManager Store，关闭时保留状态（表单草稿不丢失），任务栏显示所有打开窗口。

### 3.6 与传统布局的对比

| | 传统后台布局 | Fluent 桌面风格 |
|---|---|---|
| 导航方式 | 左侧菜单树点击 | 桌面图标单击 + 启动台搜索 |
| 多任务 | 单页面，需来回切换 | 多窗口并行，任务栏切换 |
| 学习成本 | 低（常规 Web 习惯） | 中（类似 Windows/Mac 操作） |
| 教师友好度 | 中 | 高（直观的桌面图标，降低培训成本） |
| 年长用户 | 菜单层级深时易迷失 | 桌面图标大、直观，双击即用 |
| 实现复杂度 | 低 | 中（需窗口管理器 + 拖拽库） |

## 4. 共享能力

两端共享：

- API 请求封装（JWT 通过 httpOnly Secure SameSite Cookie 存储，前端不接触 token，请求时浏览器自动携带；业务写接口自动附带 X-Request-Token 与 X-CSRF-Token；401 跳转登录页）
- 权限指令 `v-permission`
- 防重复提交 `v-prevent-duplicate`：点击后按钮 disabled + loading，接口返回后恢复。后端配合 `IdempotentMiddleware` 双重保障
- 主题 token（深色/浅色）
- 字体档位样式变量
- 工具函数（日期格式化、文件大小、MD5 计算等）

## 5. 界面能力

### 深色模式

- 支持跟随系统主题切换
- 支持用户手动切换
- 深色模式下文字、按钮、表格、状态标签清晰可辨

### 字体大小调节

- 支持标准、较大、超大三档
- 对标题、正文、表单、按钮、表格同步生效
- 照顾年长教师阅读需求

### 可用性

- 手机端点击区域足够大
- PC 端表格信息展示清晰
- 审核页面重点内容突出
- 统计页面数字、标题、标签清晰阅读

## 6. Electron 客户端打包（可选）

OA 桌面风格默认在浏览器中运行。如需原生桌面体验（系统托盘、开机自启、原生通知），可打包为 Electron 客户端。核心代码不变，Electron 仅作为壳加载 Web 页面。

### 6.1 打包结构

```
fontend/pc-electron/
├── electron/
│   ├── main.js          # 主进程：窗口管理、托盘、自启
│   └── preload.js       # 预加载脚本
├── package.json
└── build/                # electron-builder 配置
```

### 6.2 增强功能

| 特性 | 浏览器 | Electron |
|---|---|---|
| OA 桌面界面 | Y | Y |
| 系统托盘常驻 + 新消息闪烁 | N | Y |
| 开机自启 | N | Y |
| 原生通知（OS 通知中心） | N | Y |
| 桌面快捷方式 + 自定义图标 | PWA 可 | Y |
| 文件关联（双击 .xlsx 打开） | N | Y |
| 自动更新 | 浏览器自动 | 内置更新模块 |

### 6.3 分发

```
npm run build:electron
→ Windows: 实践管理系统-Setup-1.0.0.exe
→ Mac:     实践管理系统-1.0.0.dmg
→ Linux:   实践管理系统-1.0.0.AppImage
```

客户端启动时检查服务器 `/api/version` → 有新版本自动下载更新。
