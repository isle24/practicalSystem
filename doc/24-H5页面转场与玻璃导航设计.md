# H5 页面转场与玻璃导航设计

## 1. 目标

- 消除页面切换时先退场、再入场产生的停顿感。
- 主导航切换保持轻快，二级页面进入和返回保留方向感。
- 顶部导航和底部导航使用稳定、克制的玻璃效果。
- 不增加手势，不修改业务页面、接口、权限或导航历史逻辑。

## 2. 当前问题

当前页面转场使用 `mode="out-in"`，旧页面完全退出后新页面才开始进入，切换中间存在可感知空档。二级页面进入位移为视口宽度的 `22%`，移动距离随屏幕变宽，容易产生拖动和卡顿感。

## 3. 转场方案

### 3.1 渲染方式

- 页面进入和离开同时执行，不使用 `out-in`。
- 离场页面在动画期间脱离普通文档流，避免两个页面同时占据高度。
- 转场容器裁剪横向溢出，防止动画期间出现水平滚动条。
- 页面尺寸变化由新页面立即接管，不保留旧页面高度。

### 3.2 主导航切换

主导航包括首页、实习、实训、实验和我的。

- 时长：`200ms`。
- 入场：透明度 `0.72 -> 1`，纵向位移 `4px -> 0`，缩放 `0.995 -> 1`。
- 离场：透明度 `1 -> 0`，纵向位移 `0 -> -2px`，缩放 `1 -> 0.998`。
- 不使用横向位移，避免底部导航切换产生页面被推走的感觉。

### 3.3 二级页面进入

- 时长：`240ms`。
- 新页面：透明度 `0.78 -> 1`，横向位移 `12px -> 0`，缩放 `0.995 -> 1`。
- 旧页面：透明度 `1 -> 0.88`，横向位移 `0 -> -6px`。
- 使用固定像素位移，不随屏幕宽度放大。

### 3.4 二级页面返回

- 时长：`220ms`。
- 新页面：透明度 `0.82 -> 1`，横向位移 `-6px -> 0`。
- 旧页面：透明度 `1 -> 0.82`，横向位移 `0 -> 12px`，缩放 `1 -> 0.995`。
- 返回节奏略快于进入，保持操作响应感。

## 4. 玻璃导航

玻璃效果只用于顶部导航和底部导航，不作用于页面内容。

- 背景使用接近白色的半透明颜色，保证文字和图标对比度。
- 使用 `backdrop-filter: blur(20px) saturate(145%)`。
- 顶部导航增加浅色下边框，底部导航增加浅色上边框和轻微向上阴影。
- 支持 `-webkit-backdrop-filter`。
- 浏览器不支持背景模糊时，自动使用高不透明度白色背景，不影响可读性。
- 弹层打开时继续由弹层遮罩接管层级，导航玻璃层不得覆盖弹层。

## 5. 性能与可访问性

- 页面动画只改变 `transform` 和 `opacity`。
- 只对正在转场的页面设置 `will-change`，动画结束后由浏览器回收合成层。
- 背景模糊仅存在于两个固定导航区域，不对长列表和业务卡片应用模糊。
- `prefers-reduced-motion: reduce` 下关闭位移、缩放和模糊过渡，页面近乎立即切换。
- 动画期间不阻断按钮状态、导航历史和系统返回。

## 6. 验收条件

- 主导航切换没有横向推页效果和空白停顿。
- 二级页面进入、返回方向明确，但位移不超过 `12px`。
- 顶部和底部导航具有玻璃质感，文字与图标保持清晰。
- `390x844`、`430x932` 视口无横向溢出、导航遮挡和内容跳位。
- 学生、教师、学校管理员切换实习、实训、实验、消息和个人页面时无控制台错误。
- 生产构建成功，构建产物更新到 `server/public/h5`。
