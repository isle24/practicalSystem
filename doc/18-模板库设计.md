# 模板库设计

## 1. 概述

系统内置模板库，统一管理实习、实训、实验相关的各类文档模板。管理员上传和维护模板，教师和学生可在线预览和下载。

模板文件存储复用 `file_blob` + `file` 体系（见 `06-文件管理服务设计.md`），模板库仅管理分类和元数据。

## 2. 数据模型

```
template_category（模板分类）
  - id
  - code（唯一标识，如 safety_letter）
  - name（分类名称，如"安全责任书"）
  - description（分类说明）
  - sort（排序）
  - flag: on / off
  - created_at, updated_at, deleted_at

template（模板文件）
  - id
  - category_id（关联 template_category.id）
  - name（模板名称，如"实习安全责任书（2026版）"）
  - description（模板说明）
  - file_id（关联 file.id，实际文件）
  - version（版本号，如 "2026.1"）
  - download_count（下载次数）
  - flag: on / off（off 时前端不展示，不删除文件）
  - created_at, updated_at, deleted_at
```

## 3. 预置分类

系统初始化时创建以下 7 个分类：

| code | name | 说明 |
|---|---|---|
| internship_requirement | 实习要求模板 | 实习大纲、实习计划、实习要求说明等 |
| safety_letter | 安全责任书 | 实习安全责任书、实验室安全承诺书 |
| position_cert | 岗位证明模板 | 实习岗位证明、企业接收函 |
| guardian_consent | 监护人知情同意书 | 自主实习监护人同意书、外出实践同意书 |
| tripartite_agreement | 三方协议模板库 | 学校-企业-学生三方协议 |
| process_document | 过程文档模板库 | 日志模板、周报模板、签到表、检查记录表 |
| report_template_lib | 实习报告模板库 | 实习报告模板（不含 form_schema 的纯文档模板，与 report_template 表互补） |

> `report_template_lib` 分类存放报告的 Word/PDF 参考模板。带表单的在线报告模板使用 `report_template` 表（见 `08-实习管理模块设计.md`），两者互补：模板库提供参考文档，report_template 提供在线填写。

## 4. 管理员操作（PC 端）

**模板管理页面：** "系统管理 → 模板库"

**上传模板：**

```
1. 选择分类 → 填写模板名称、说明、版本号
2. 上传文件（走 file 服务，支持 doc/docx/pdf/xls/xlsx/zip）
3. 文件通过上传校验（类型白名单、大小 ≤ 50MB）
4. 保存 → template 记录（flag=on）
```

**编辑模板：**

```
- 修改名称、说明、版本号、分类
- 替换文件：上传新文件 → 旧 file 记录 ref_count-1 → 新 file 记录关联
- 不可编辑：download_count
```

**预览模板：**

```
点击"预览" → 后端返回文件 URL
  → PDF/图片：浏览器内嵌预览（iframe / <object>）
  → Office 文档：默认生成缩略图并提示下载；如学校允许外网服务，可配置 Office Online 作为可选预览通道
  → 不可预览格式（zip 等）：显示"请下载后查看"
```

Office Online 属于外部服务依赖，内网或有合规要求的学校默认关闭，不作为系统必需能力。

**禁用/启用：**

```
flag=off → 前端不展示，不删除文件和记录
flag=on  → 恢复正常显示
```

**删除：**

```
软删除 → flag=off + deleted_at
文件不物理删除（可能有其他引用）
```

## 5. 教师/学生操作（H5 + PC）

**浏览模板库：**

H5 端："资源 → 模板库"，PC 端：顶部导航"模板库"

```
模板库
├── 分类 Tab：实习要求 / 安全责任书 / 岗位证明 / 监护人同意书 / 三方协议 / 过程文档 / 实习报告
└── 模板列表（按更新时间倒序）
    ├── 模板名称 + 版本号
    ├── 说明摘要
    ├── 文件类型图标（Word/PDF/Excel）
    ├── 下载次数
    └── 操作：[预览] [下载]
```

**下载：**

```
点击"下载" → 调 file 服务获取 URL（带签名或直接 URL）
→ file.download_count + 1
→ 浏览器触发下载
```

**预览：**

```
点击"预览" → 同管理员预览逻辑
→ 不增加 download_count
```

## 7. 与报告模板的关系

| | 模板库（template） | 报告模板（report_template） |
|---|---|---|
| 用途 | 参考文档，下载后自行填写 | 在线填写表单，系统生成文档 |
| 文件 | doc/docx/pdf 等 | form_schema JSON |
| 填写方式 | 下载 → 本地编辑 → 上传提交 | 在线表单 → 系统渲染 Word/PDF |
| 管理入口 | 系统管理 → 模板库 | 实习管理 → 报告模板配置 |
| 用户交互 | 下载/预览 | 在线填写/提交 |
