# 桌面客户端实施计划

使用 Tauri 2、Rust 和 Vue 3，PC 页面编译进客户端，接口连接学校服务器。按以下顺序在当前任务执行，不派子智能体，不新增业务逻辑、数据库表或后端路由。

## 连接与窗口

- [x] `fontend/desktop/package.json`、`vite.config.js`、`src/App.vue`：学校域名输入、连接中状态、错误反馈、保存地址和进入学校。
- [x] `fontend/desktop/src-tauri/src/connection.rs`：域名规范化、HTTPS/本机 HTTP 校验、读取学校公开配置、本机连接配置持久化。
- [x] `fontend/desktop/src-tauri/src/windows.rs`：原生业务窗口、站内关联窗口、站外浏览器跳转、下载与打印兼容。
- [x] `fontend/desktop/src-tauri/src/gateway.rs`：仅回环监听的接口与文件通道，独立 Cookie 会话、来源限制和流式上传下载。
- [x] `fontend/pc/src/api/client.js`：复用浏览器接口逻辑，站内附件映射至本机会话，对外分享链接使用学校公网域名。
- [x] `fontend/desktop/src-tauri/src/lib.rs`：应用菜单、连接命令、窗口关闭和再次打开处理。
- [x] `fontend/desktop/src-tauri/capabilities/`：权限只开放给本地连接页，远程页面不获得原生 IPC 能力。

## 构建与交付

- [x] 创建 Tauri 配置、Cargo 锁文件、应用图标和忽略规则。
- [x] 本机前端编译、`cargo fmt --check`、`cargo clippy --locked -- -D warnings`、Apple Silicon 安装包构建与教师登录核对。
- [x] `.github/workflows/desktop-build.yml`：Windows NSIS 与 Linux deb/AppImage 构建，产物保存在 Actions Artifacts，不自动公开发布。
- [ ] 核对 GitHub 仓库可见性和已有分支，保留 Gitea `origin`，提交客户端文件并运行云端构建。
- [ ] 将安装说明、域名设置、构建命令和实际平台限制写入 `doc`，提交并推送 Gitea 主分支。
