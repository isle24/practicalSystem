# 实践管理系统建设方案

## 1. 项目背景

为提升学校实践教学管理的信息化水平，规范实习、实训、实验等业务流程，建设一套统一的实践管理系统。系统面向学校管理员、教师、学生及企业用户，依托企业微信作为主要访问入口，同时支持 PC 浏览器访问，实现实践教学全过程的在线管理、过程留痕、结果统计和数据导出。

## 2. 建设目标

本项目建设目标如下：

- 建设统一的实践教学业务管理平台
- 建设统一的登录认证、角色权限、消息提醒和日志审计机制
- 建设实习管理、实训管理、实验管理三大业务模块
- 提升学校、教师、学生、企业之间的在线协同效率
- 提供适配移动端与 PC 端的统一使用体验
- 提供适合教师长期使用的界面能力，包括深色模式和字体大小调节

## 3. 建设原则

本项目按照以下原则建设：

- 统一平台：统一前端、统一后端、统一权限、统一数据管理
- 稳定可用：确保核心业务流程稳定运行
- 易于推广：兼顾企业微信移动端与 PC 浏览器访问场景
- 易于维护：采用清晰的技术架构和标准化接口设计
- 易于使用：重视年长教师和管理人员的阅读与操作体验

## 4. 总体建设内容

系统建设内容包括以下几个部分：

- 统一登录认证中心
- 用户与权限管理中心
- 基础档案管理中心
- 实习管理模块
- 实训管理模块
- 实验管理模块
- 消息提醒与待办中心
- 日志审计与统计导出中心

## 5. 总体技术路线

### 5.1 前端技术路线

前端拆分为两个独立项目，各自采用最优技术栈：

| 端 | 框架 | UI 库 | 说明 |
|---|---|---|---|
| H5 移动端 | Vue 3 | Vant 4 | 企业微信内嵌 / 手机浏览器 |
| PC 管理端 | Vue 3 | Element Plus | 管理员后台 |

两端独立构建、独立部署，系统根据角色权限动态展示不同菜单、页面和操作按钮。

### 5.2 后端技术路线

后端统一采用 `PHP 8.4 + Webman` + `illuminate/database`（Laravel ORM）实现，严格 MVC 模式，负责：

- 登录认证
- 接口服务
- 权限校验
- 业务处理
- 消息任务
- 日志审计
- 统计导出

### 5.3 数据与缓存技术路线

- 数据库采用 MySQL，每学校独立数据库，物理隔离
- 缓存与异步任务采用 Redis（共享）
- 文件采用本地存储（public/files/），nginx 直链

## 8. 界面与交互方案

### 8.1 双端界面方案

系统采用 H5 移动端和 PC 管理端两套独立前端项目。

| 端 | 使用场景 | UI 库 |
|---|---|---|
| H5 移动端 | 企业微信内嵌、手机浏览器 | Vant 4 |
| PC 管理端 | 管理员后台操作 | Element Plus |

两端特点：

- 同一后端接口服务
- 同一权限体系控制
- 不同角色显示不同功能
- 各自终端体验最优

### 8.2 深色模式

系统提供深色模式和浅色模式。

要求如下：

- 支持跟随系统主题切换
- 支持用户手动切换
- 深色模式下保证文字、按钮、表格、状态标签清晰可辨

### 8.3 字体大小调节

系统提供全局字体大小调节功能。

要求如下：

- 支持标准、较大、超大三档
- 对标题、正文、表单、按钮、表格同步生效
- 重点照顾年长教师阅读需求

### 8.4 可用性要求

- 手机端点击区域足够大
- PC 端表格信息展示清晰
- 审核页面重点内容突出
- 统计页面数字、标题、标签可清晰阅读

## 9. 企业微信接入方案

接入流程如下：

1. 用户从企业微信工作台进入系统
2. 前端发起 OAuth 授权
3. 后端获取企业微信身份信息
4. 完成系统用户绑定
5. 返回登录令牌
6. 进入对应角色页面开展业务处理

## 10. 安全与稳定性方案

建设内容如下：

- 使用 JWT 进行接口认证
- 按角色和数据范围控制访问权限
- 敏感操作记录日志（敏感字段自动脱敏）
- 密码使用 `password_hash(PASSWORD_BCRYPT)` 自动加盐存储，`password_verify()` 验证
- TOTP 密钥、API Key、数据库密码等敏感凭证加密存储（AES-256-GCM）
- 附件访问权限控制
- 防重复提交
- 接口限流
- 使用 Redis 队列处理异步消息和导出任务

## 11. 部署方案

建议部署方式如下：

- 前端发布为 H5
- 后端部署在 Linux 服务器
- Nginx 反向代理 Webman
- MySQL 作为主数据库
- Redis 作为缓存和队列

项目目录：

- 后端目录：`server`（Webman 项目根）
- 前端目录：`fontend`（源码，编译输出到 server/public/h5 和 server/public/pc）
- 文档目录：`doc`

## 12. 项目结论

本建设方案采用 `H5 移动端（Vant 4）+ PC 管理端（Element Plus）+ PHP 8.4 + Webman 后端` 的双端技术路线，能够同时满足企业微信移动端访问和 PC 浏览器管理需求，并通过角色权限控制、深色模式、字体大小调节等能力，满足不同用户群体尤其是教师群体的长期使用需求。方案功能完整、边界明确、可实施性强，可作为后续正式开发和客户沟通的依据。
