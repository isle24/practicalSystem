# 前端视觉与交互规范

## 1. 适用范围

本规范约束以下前端界面，不调整业务流程、权限规则和后端接口：

- PC 端：`fontend/pc`
- H5 端：`fontend/h5`
- PC 构建产物：`server/public/pc`
- H5 构建产物：`server/public/h5`

PC 端采用业务型 Fluent 桌面，主界面遵循 Windows 11 的窗口与任务栏习惯，启动台采用 macOS Launchpad 的全屏应用网格。H5 端采用原生 App 信息架构，减少浏览器工具栏和后台页面缩放感。

## 2. 现有问题

### 2.1 PC 端

- 顶部栏、窗口、任务栏和启动台分别使用不同的视觉语言。
- 启动台全屏遮罩颜色过重，应用缺少分组、分页和清晰的添加状态。
- 窗口控制按钮、任务栏运行状态和激活窗口反馈不够接近桌面系统。
- 桌面图标背景块面积偏大，图标、标签和壁纸之间的层级不够清晰。
- 模块内部仍存在传统后台页面感，标题、工具栏、筛选区和表格的垂直空间利用不统一。
- 登录页功能完整，但材质、焦点状态和学校品牌呈现较弱。

### 2.2 H5 端

- 前进、后退、刷新、退出长期占用顶部区域，属于浏览器式操作。
- 当前角色和数据范围在每个页面重复显示，压缩首屏业务内容。
- 首页模块入口与底部导航重复。
- 底部导航超过常用 App 的五项上限，文字和图标密度偏高。
- 列表、表单、统计和流程记录均使用相似白色卡片，信息层级不足。
- 页面级操作缺少统一的固定底部操作区，长表单提交不方便。

## 3. 视觉基础

### 3.1 色彩

| 用途 | 建议值 | 说明 |
|---|---|---|
| 主操作 | `#2563EB` | 查询、提交、当前导航 |
| 成功 | `#16875D` | 已通过、已完成、启用 |
| 警告 | `#B66A00` | 待处理、即将截止 |
| 危险 | `#C9364F` | 退回、删除、异常 |
| 主文字 | `#18212B` | 标题、正文 |
| 次文字 | `#5F6B78` | 说明、辅助字段 |
| 页面背景 | `#F2F5F8` | PC 窗口内容、H5 页面 |
| 内容表面 | `#FFFFFF` | 表格、表单、弹层 |
| 分割线 | `#D8E0E8` | 边框、分组 |

不使用单一蓝色覆盖全部界面。业务模块图标可分别使用蓝、绿、青、橙、红和灰，状态色只表达状态，不作为大面积背景。

### 3.2 尺寸与间距

- 基础间距使用 `4 / 8 / 12 / 16 / 24 / 32px`。
- 普通卡片和输入控件圆角不超过 `8px`。
- PC 图标按钮保持稳定方形尺寸，禁止由文字和加载状态改变尺寸。
- H5 可点击区域最小高度为 `44px`。
- 页面标题、面板标题、表格标题按容器层级使用不同字号，禁止在紧凑面板中使用大标题。
- 文字不使用负字距，不按视口宽度缩放字号。

### 3.3 动效

- 普通悬停和选中反馈使用 `120-180ms`。
- 窗口打开、最小化和启动台显示使用 `180-240ms`。
- 尊重系统的减少动态效果设置。
- 动效只表达状态变化，不延迟业务操作。

## 4. PC 端规范

### 4.1 登录页

- 页面只显示学校背景图和登录面板。
- 登录面板居中，使用轻度半透明白色表面和背景模糊。
- 学校名称作为主要品牌信息，不显示学校代码。
- 输入框显示明确的聚焦边框，登录按钮显示加载和禁用状态。
- 背景图缺失时使用低对比度中性背景，不使用装饰性渐变图形。

### 4.2 桌面框架

- 顶部工具栏高度控制在 `44-48px`，保留学校品牌、全局搜索、通知、头像和账号操作。
- 顶部工具栏使用浅色半透明材质，壁纸仍可辨识，文字保持足够对比度。
- 桌面区域不放置业务统计卡片，只放快捷方式和打开的窗口。
- 快捷方式采用固定网格，图标与标签形成一个点击区域。
- 快捷方式默认无大块背景；悬停、选中时才显示半透明底色和细边框。
- 快捷方式使用单击打开，避免网页中双击造成误解或重复打开。
- 右键菜单沿用桌面习惯，提供启动台、刷新、个性化、个人设置等明确命令。

### 4.3 全局搜索

- 顶部搜索用于快速查找模块、菜单页面和可跳转消息。
- 搜索结果显示图标、名称和所属模块，键盘上下键选择，回车打开。
- 无结果时显示简短空状态，不保留空白下拉层。
- 搜索结果打开后关闭结果层，并聚焦对应窗口。

### 4.4 任务栏

- 任务栏高度控制在 `46-50px`，使用 Windows 11 式半透明表面。
- 启动台按钮和已打开应用在中部排列，系统状态、消息和时间位于右侧。
- 已打开应用显示运行标记，当前窗口显示激活标记。
- 点击当前激活应用时最小化，点击其他应用时恢复并聚焦。
- 同一模块只维护一个主窗口实例；需要独立处理的详情窗口使用独立窗口 ID。
- 图标按钮只显示图标，使用工具提示说明含义。

### 4.5 启动台

- 启动台为全屏覆盖层，使用当前桌面壁纸的模糊和轻度暗化效果。
- 顶部居中显示搜索框，右上角提供关闭按钮。
- 应用采用 Launchpad 式网格，显示统一尺寸图标和单行名称。
- 应用按教学业务、数据与配置、个人工具进行视觉分组。
- 应用数量超过当前视口容量时分页显示，底部显示页码圆点。
- 搜索状态下跨分组过滤，不分页隐藏匹配结果。
- 可添加桌面的应用显示圆形添加按钮；已添加显示勾选状态；默认应用显示锁定状态。
- 添加和移除快捷方式后立即更新桌面，不刷新页面。
- 收藏夹作为应用入口保留在启动台，并支持添加到桌面。
- 点击应用打开对应窗口；点击应用、搜索框、添加按钮以外的空白区域关闭启动台。

### 4.6 窗口

- 窗口使用统一的 `8px` 圆角、细边框和分层阴影。
- 激活窗口标题栏和边框需要有可辨识的焦点状态。
- 标题栏包含应用图标、窗口标题、最小化、最大化和关闭。
- 控制按钮使用 Windows 式矩形悬停区域，关闭按钮悬停显示危险色。
- 双击标题栏切换最大化和还原。
- 窗口支持拖动、八方向缩放、最小化、最大化、关闭和任务栏恢复。
- 最大化窗口填满可用工作区，不覆盖顶部工具栏和任务栏。
- 窗口尺寸变化不能导致表格操作列、分页和弹窗溢出。
- 多窗口按打开顺序错位排列，禁止新窗口完全遮住前一个窗口标题栏。

### 4.7 模块内容

- 左侧模块菜单只负责模块内导航，右侧不重复显示同一菜单。
- 右侧顶部固定显示当前模块名称和操作说明入口。
- 列表页面按“筛选栏、操作栏、表格、分页”排列，表格占用主要高度。
- 筛选条件按届次、学院、专业、班级、关键词顺序排列。
- 查询和重置放在筛选栏末端；新增、导入、导出放在独立操作区。
- 表格操作列固定在右侧，状态列使用统一标签。
- 新增、编辑、详情和审核使用窗口内弹层，优先在当前窗口高度内完整显示。
- 弹层内容较多时只滚动内容区，标题和底部操作保持固定。

## 5. H5 端规范

### 5.1 App 框架

- 未登录时只显示学校品牌和登录表单，不显示底部导航、角色卡片和数据范围。
- 底部导航固定为：首页、实习、实训、实验、我的。
- 消息中心位于顶部导航右侧，使用未读角标提示。
- 一级页面顶部显示当前页面标题和必要操作，不显示返回按钮。
- 详情、表单、审核和流程记录页面显示返回按钮。
- 页面刷新采用下拉刷新，不提供常驻刷新按钮。
- 退出登录放入“我的”，不提供常驻退出按钮。
- 角色和数据范围只在首页身份区和“我的”中显示。
- 顶部与底部均适配设备安全区。

### 5.2 首页

- 首页顶部显示学校名称、用户称呼、当前角色和消息入口。
- 首页不重复展示底部导航中的全部模块。
- 学生首页优先显示当前阶段、最近截止时间、待提交和需修改事项。
- 教师首页优先显示待审核、即将截止任务和指导学生动态。
- 管理员首页优先显示异常数据、待处理流程和关键统计入口。
- 常用操作控制在首屏内，次要内容通过“查看全部”进入对应模块。

### 5.3 列表与筛选

- 一级列表顶部显示搜索框和筛选按钮。
- 届次、学院、专业、班级和状态等条件放入底部筛选面板。
- 筛选按钮显示已选条件数量；角色默认范围自动带入并限制可选范围。
- 每条记录优先展示标题、状态、对象、时间和两个以内关键字段。
- 次要字段进入详情，不在列表卡片中堆叠。
- 分页采用滚动加载或明确的“加载更多”，不得一次加载全部数据。
- 空状态说明当前列表为空，错误状态提供重试操作。

### 5.4 详情、表单与审核

- 详情页使用分组信息区，不使用卡片嵌套卡片。
- 新增和编辑使用全屏页面；少量字段可使用底部抽屉。
- 表单字段按业务顺序单列排列，标签、输入、校验提示保持稳定间距。
- 主要提交操作固定在底部安全区上方。
- 草稿和提交审核同时存在时，草稿为次按钮，提交审核为主按钮。
- 审核页先显示提交对象、提交内容和流程记录，再显示审核意见。
- 审核状态使用分段选择，通过、退回和修改按业务权限显示。
- 审核意见显示当前字数和限制，超过上限不能继续输入。
- 请求期间禁用重复提交，超时后恢复按钮并显示明确提示。

### 5.5 消息中心

- 消息按日期分组，时间作为弱信息，标题和内容作为主信息。
- 未读、紧急、待办和结果使用状态标识，不使用大面积彩色背景。
- 点击关联消息进入对应业务详情，返回后保留消息列表位置。
- 全部已读作为次要操作，不占用主要导航位置。

### 5.6 我的

- 顶部显示头像、姓名、角色和学校名称。
- 账号切换仅在存在可切换账号时显示。
- 个人资料、消息设置、账号安全、文档中心和模板库按功能分组。
- 退出登录放在页面底部，并进行二次确认。

## 6. 组件边界

### 6.1 PC 公共组件

| 组件 | 职责 |
|---|---|
| `DesktopShell` | 顶部栏、工作区、任务栏和全局覆盖层 |
| `DesktopTopbar` | 品牌、搜索、通知和账号入口 |
| `DesktopTaskbar` | 启动台入口、运行窗口和系统状态 |
| `DesktopLauncher` | 应用分组、搜索、分页和桌面快捷方式 |
| `DesktopWindow` | 窗口位置、尺寸、焦点和控制按钮 |
| `DesktopShortcut` | 桌面图标、名称、选中和打开交互 |
| `DataListPanel` | 筛选、表格、固定操作列和分页 |
| `OperationDialog` | 新增、编辑、详情和审核弹层框架 |
| `StatusBadge` | 业务状态文本、颜色和图标映射 |

### 6.2 H5 公共组件

| 组件 | 职责 |
|---|---|
| `MobileAppShell` | 安全区、顶部导航、页面容器和底部导航 |
| `MobilePageHeader` | 返回、标题、消息和页面操作 |
| `RoleHomePanel` | 学生、教师、管理员首页内容框架 |
| `MobileFilterSheet` | 搜索条件、默认范围和重置确认 |
| `MobileRecordCell` | 列表记录、状态、关键字段和操作入口 |
| `MobileFormPage` | 表单滚动区和固定底部操作区 |
| `ReviewPanel` | 提交内容、流程记录、审核状态和意见 |
| `FlowTimeline` | recording 与 review opinion 的流程展示 |
| `StatusBadge` | 与 PC 共用状态语义 |

公共组件只提供布局、状态和交互能力，业务模块通过配置和插槽传入字段、按钮与权限结果，不在公共组件中写业务判断。

## 7. 状态与数据流

- 菜单接口决定 PC 启动台、桌面快捷方式和模块导航的可见范围。
- 桌面配置接口决定壁纸、快捷方式和收藏夹，不由前端写死用户配置。
- PC 窗口管理状态统一维护窗口 ID、位置、尺寸、最小化、最大化和层级。
- 全局搜索只消费已有菜单、消息和模块数据，不新增独立业务接口。
- H5 底部导航根据权限隐藏不可用模块，但顺序保持固定。
- H5 首页消费现有汇总和待办数据，角色只决定展示优先级，不改变后端数据范围。
- 页面切换保留当前筛选、滚动位置和未提交表单状态。
- 登录失效统一回到登录页，并清理仅与当前账号相关的前端状态。

## 8. 异常与反馈

- 页面首次加载显示骨架，不使用空白区域代替加载状态。
- 局部接口失败只影响对应区域，不覆盖整个桌面或 App。
- 成功反馈使用短提示；需要用户处理的问题保留在当前页面。
- 上传显示进度、文件限制和失败原因。
- 提交按钮在请求期间显示加载并禁用，接口返回或超时后恢复。
- 删除、退回、通过后修改和退出等操作必须二次确认。
- 权限不足时隐藏无权限入口；直接访问无权限页面时显示明确提示并提供返回操作。

## 9. 实施边界

- 不修改现有业务状态机、审核规则、权限范围和 API 协议。
- 不修改 Webman 框架、默认路由和第三方组件源码。
- 优先拆分现有超大页面中的公共框架和可复用视图，不进行无关重构。
- PC 与 H5 使用各自 UI 库的标准能力，Lucide 作为统一图标来源。
- 前端构建完成后分别同步到 `server/public/pc` 和 `server/public/h5`。

## 10. 完成标准

- PC 登录、桌面、启动台、窗口、任务栏和模块内容使用统一视觉语言。
- 启动台保留全屏 Launchpad 体验，桌面与窗口符合 Windows 常用操作习惯。
- H5 首屏不再显示浏览器式前进、后退、刷新和退出工具栏。
- H5 底部导航不超过五项，消息入口和未读状态始终可访问。
- 学生、教师和管理员首页突出各自最常用工作。
- PC 常用分辨率和 H5 常用手机宽度下无文字遮挡、控件重叠和不可达操作。
- 所有列表、弹层、表单和状态反馈遵循统一组件规则。
