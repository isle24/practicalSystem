# 教务与实时消息实施

## 已确认边界

- 教务批次差异以字段、原值、新值呈现，不展示密文或身份校验摘要。
- 智能体首版只做问答；学校管理员配置兼容接口、模型和密钥。只发送用户主动输入的会话，不自动读取档案、审批、成绩或执行 SQL。
- WebSocket 只推送消息列表失效通知；消息和待办仍以学校库中的现有记录为准。断线重连后通过鉴权 HTTP 接口补取。
- 安装包可以按平台延期下载；已发布版本的延期平台校验完成后自动开放。未校验包不能下载或更新。
- 客户端再次登录显示学校名称及本地备注，切换学校时才输入域名。

## 账号规则待确认

已确认保留先绑定再登录。当前批次发布已同步学生和教师基础档案；设计文档要求企业微信首次校验后创建账号，但代码目前只有身份校验服务，没有接通企业微信绑定入口。待明确是企业微信自助绑定还是后台档案关联后，再实现账号批量创建。不得直接生成可登录的学生账号绕过绑定，也不得修改已有账号密码。
