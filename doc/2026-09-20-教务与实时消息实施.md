# 教务与实时消息实施

## 已确认边界

- 教务批次差异以字段、原值、新值呈现，不展示密文或身份校验摘要。
- 智能体首版只做问答；支持学校管理员配置和个人配置两种来源，个人密钥服务端加密保存。只发送用户主动输入的会话，不自动读取档案、审批、成绩或执行 SQL。
- WebSocket 只推送消息列表失效通知；消息和待办仍以学校库中的现有记录为准。断线重连后通过鉴权 HTTP 接口补取。
- 安装包可以按平台延期下载；已发布版本的延期平台校验完成后自动开放。未校验包不能下载或更新。
- 客户端再次登录显示学校名称及本地备注，切换学校时才输入域名。

## 已确认账号规则

已确认保留先绑定再登录，采用企业微信自助绑定。当前批次发布已同步学生和教师基础档案；代码目前只有身份校验服务，没有接通企业微信绑定入口。档案有手机号时验证短信，确实无手机号时比较学号、姓名和完整身份证号；缺少两类资料须先补齐。不得直接生成可登录的学生账号绕过绑定，也不得修改已有账号密码。个人/学校问答配置的后续修改见《2026-09-20-个人与学校问答配置实施》。
