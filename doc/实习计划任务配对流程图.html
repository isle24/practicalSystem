成都锦城学院实习计划任务配对流程图

上面是主干，下面是任务分支。每条任务分支都独立走完“任务 → 班级 → 多学生 → 多条 pair → 材料成绩”，避免把同一老师的不同任务混在一起。
1. 实习课程计划 从教务系统抽取或手动补录。按届次、学院、专业、课程、学分、计划人数生成。
→
2. 拆分实习任务 一个计划可拆分多个任务。每个任务必须有唯一负责老师、时间、地点和批次。
→
3. 任务规则校验 同一老师可承担多个任务，但任务时间不能冲突；任务编号在计划下唯一。
任务分支：每个任务都是独立业务边界
任务 A 张老师 / 第一批 时间段 A，地点 A。该任务只由张老师负责。
→
绑定班级 1 班 + 2 班写入 internship_task_class。
1 班 2 班
→
展开多名学生 系统按班级名单展开，得到 38 名学生。
学生 01 学生 02 ... 学生 38
→
生成 38 条 pair 每条记录都有 student_id、teacher_id、arrangement_id。
→
材料与成绩独立 任务 A 的签到、日志、报告、审核、成绩只挂任务 A。
任务 B 张老师 / 第二批 时间段 B，地点 B。同一老师的另一个任务。
→
绑定班级 3 班写入 internship_task_class。
3 班
→
展开多名学生 系统按班级名单展开，得到 24 名学生。
学生 39 学生 40 ... 学生 62
→
生成 24 条 pair 任务 B 的 pair 与任务 A 完全分开。
→
材料与成绩独立 老师端也必须按任务筛选，不能把 A/B 学生合并。
任务 C 李老师 / 第一批 时间段 C，地点 C。不同老师也遵循同一规则。
→
绑定班级 4 班 + 5 班写入 internship_task_class。
4 班 5 班
→
展开多名学生 系统按班级名单展开，得到 42 名学生。
学生 63 学生 64 ... 学生 104

生成 42 条 pair 同一学生在同一任务下只能有一条 active pair。
→
材料与成绩独立 课程汇总时再按计划 score_rule 汇总各任务成绩。
课程成绩汇总 如果学生参与多个任务，成绩按任务分别记录，再按计划规则计算最终成绩。
→
材料归档 按届次、课程、任务、学生归档，支持抽检和完整率统计。
→
历史追溯 任务变更保留旧任务、旧 pair、旧审核记录，再重新确认绑定。

关键约束

任务是边界签到、日志、报告、审核、成绩都必须绑定具体 arrangement_id。
一任务一老师每个任务只能有一个负责老师，不能一个任务多个老师。
一任务多学生任务可绑定多个班级，展开后每名学生生成一条 pair。
同老师多任务同一老师可有多个任务，但时间段必须错开，学生集合必须分开。
变更留痕任务、班级、学生范围变更时保留旧历史，不覆盖已执行数据。
