# 实习基地、计划、任务与实施改造实施计划

> **执行说明：** 按任务顺序在当前 `master` 工作区执行。每个阶段完成后单独提交，前端编译产物同步写入 `server/public/pc`。

**目标：** 完成基地建设结构化维护、教学计划主动拉取与待接收确认、计划表、实习任务、实习实施、模板化 Word/PDF 导出和统一列表交互。

**架构：** 保留 `internship_plan -> arrangement -> pair` 数据关系，通过学校业务库子表保存基地申报重复信息、人员快照、预算和实施组织安排。控制器只接收参数并调用服务，所有业务查询集中到 Model 方法。

**技术栈：** PHP 8.4、Webman、Illuminate Database、PhpSpreadsheet、Vue 3、Element Plus、Vite、现有文件管理服务。

导出依赖固定为 `phpoffice/phpword:^1.3` 和 `mpdf/mpdf:^8.2`。Word 使用 `TemplateProcessor`，PDF 使用 mPDF，并通过现有文件服务返回下载信息。

## 全局约束

- 所有业务表位于学校业务库，不新增学校租户字段。
- 不修改 Webman 默认路由和框架代码。
- 不删除 `internship_plan`、`arrangement`、`base`、`base_application`、`implementation_sheet` 及历史记录。
- 计划主表不新增学生人数业务录入。
- 不恢复学期和学年筛选；毕业实习使用毕业届次，其他实习使用年级。
- 基地当前保存后直接生效，不设置线上审核。
- 教务计划当前只支持后台主动拉取；先写入待接收表，管理员确认后生成草稿计划，不推送任务落实数据。
- 不新增测试文件；使用 PHP 语法检查、前端构建和运行接口检查进行验证。
