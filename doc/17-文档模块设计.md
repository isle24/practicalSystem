# 文档模块设计

## 1. 概述

系统内置帮助文档模块，超级管理员/学校管理员可编写和维护使用说明。新功能开发完成后，管理员在后台编辑对应文档，H5 和 PC 端用户可随时查阅。

文档按模块组织，支持 Markdown 编写、版本管理、发布/草稿状态、搜索。

## 2. 数据模型

```
doc_category（文档分类，对应系统模块）
  - id, parent_id（树形）
  - code（唯一标识，如 internship / training / lab / system / user）
  - name（分类名称，如"实习管理"）
  - icon（图标）
  - sort
  - status: enabled / disabled
  - created_at, updated_at, deleted_at

doc_article（文档文章）
  - id
  - category_id（关联 doc_category）
  - title（标题）
  - content（Markdown 正文）
  - version（版本号，如 1.0, 1.1）
  - status: draft / published / archived
  - author_id（作者 account.id）
  - view_count（阅读次数）
  - published_at（发布时间）
  - created_at, updated_at, deleted_at

doc_article_history（编辑历史，可回溯）
  - id, article_id
  - title, content（该版本快照）
  - version
  - editor_id（编辑人 account.id）
  - change_note（变更说明）
  - created_at
```

## 4. 文档编写（PC 端）

管理员在 PC 端"系统管理 → 文档管理"中编写：

**编辑器：**
- Markdown 编辑器（左右分栏：编辑 + 实时预览）
- 支持图片上传（走 file 服务）
- 支持内部链接（`[实习申请](@/internship/application)` → 自动转为实际路径）
- 支持变量替换（`{school_name}` → 当前学校名称）

**发布流程：**

```
新建/编辑文章
  → 保存草稿（status=draft）
  → 预览效果
  → 点击"发布"
  → 填写变更说明
  → version 自动递增（1.0 → 1.1）
  → status=published
  → 旧版本快照存入 doc_article_history
```

**版本回溯：**

```
文章详情页 → "历史版本"标签
  → 版本列表（版本号、编辑人、时间、变更说明）
  → 点击某版本 → 查看该版本的渲染内容
  → "恢复此版本" → 创建新版本（内容=旧版本，version+1）
```

## 5. 文档查看（H5 + PC）

**H5 端（"我的 → 帮助中心"）：**

```
帮助中心
├── 搜索框（全文搜索标题 + 内容）
├── 分类导航（手风琴展开）
└── 常见问题（按浏览量排序）
```

文档详情页：
- 顶部标题 + 更新时间
- Markdown 渲染内容
- 底部："此文档有帮助吗？"（是/否按钮，用于改进）
- 相关文档推荐（同分类下其他文章）

**PC 端（顶部导航栏"帮助"入口）：**

```
左侧：分类树
右侧：文档内容（Markdown 渲染）
顶部：搜索框 + 面包屑导航
```

## 6. 搜索

`doc_article` 表建立全文索引（MySQL FULLTEXT 或 Elasticsearch 预留）：

```sql
ALTER TABLE doc_article ADD FULLTEXT INDEX ft_doc (title, content);
```

搜索接口：

```
GET /api/doc/search?q=实习申请&category=internship

返回：匹配的文章列表（标题、摘要（前 200 字符）、分类、更新时间）
```

## 7. 新功能联动的文档生成流程

新功能开发完成后，管理员编写对应文档的标准流程：

```
1. 开发完成新功能（如"一键模拟登录"）
2. 管理员登录 PC 端 → 文档管理
3. 在对应分类下新建文章：
   → 标题："一键模拟登录使用说明"
   → 使用 Markdown 模板快速填充（系统提供预设模板）
   → 编写操作步骤、截图说明、注意事项
4. 保存并发布
5. H5/PC 端用户即可在帮助中心查看
```

**预设模板：**

```markdown
# {功能名称}使用说明

## 适用角色
{角色列表}

## 操作步骤
1. 
2. 
3. 

## 注意事项
- 

## 常见问题
**Q：**
**A：**
```

## 8. 管理界面（PC 端）

- 分类管理：树形列表，增删改查，拖拽排序
- 文章管理：按分类筛选，表格展示（标题、版本、状态、作者、阅读量、更新时间）
- 编辑器：Markdown 编辑 + 实时预览
- 版本历史：时间线展示，支持查看和恢复
- 批量操作：批量发布、批量归档

## 9. 权限

| 角色 | 权限 |
|---|---|
| super_admin | 当前学校库全部分类 + 文章 CRUD |
| school_admin | 当前学校库分类 + 文章 CRUD |
| college_admin | 仅查看，不可编辑 |
| teacher | 仅查看 |
| student | 仅查看 |
| enterprise | 仅查看 |

## 10. 配置项

```
doc:
  ├── search_enabled       是否启用全文搜索（默认 true）
  └── feedback_enabled     是否启用"有帮助"反馈（默认 true）
```
