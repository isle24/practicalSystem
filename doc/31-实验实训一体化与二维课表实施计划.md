# 实验实训一体化与二维课表实施计划

> 实施时逐项更新勾选状态。根据项目规则不创建测试文件，仅执行语法、构建、接口和浏览器验证。

**目标：** 将实验、实训合并为统一模块，并实现按届次、学院、专业编排的周二维课表。

**架构：** 继续使用统一 `practice_*` 表，通过 `module_type` 区分类别；新增全局课节表和统一 `PracticeController`。PC 使用独立二维课表组件，H5 使用统一入口和类别标签。

**技术栈：** PHP 8.4、Webman、Webman 默认路由、Illuminate Database、Vue 3、Element Plus、Vant。

## 全局约束

- 所有学校业务数据位于学校业务库，不增加学校字段。
- 所有查询由 Model 方法封装，Controller 和 Service 不拼接查询条件。
- 不修改框架代码和路由配置。
- 不恢复学期和学年，筛选层级为届次、学院、专业。
- 不删除现有实验、实训业务记录。
- 不保留 `/api/training/*` 和 `/api/lab/*` 兼容接口。
- 前端构建产物同步到 `server/public/pc` 和 `server/public/h5`。
