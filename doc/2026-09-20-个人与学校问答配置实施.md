# 个人与学校问答配置

## 已确认规则

- 学校配置由学校管理员、超级管理员维护，普通用户不读取密钥。
- 个人配置按学校、登录账号隔离，服务端加密保存，PC/H5/客户端共用。
- 明确选择学校或个人服务，不自动回退；切换服务新建会话，不向另一服务发送旧会话。
- 队列记录服务来源与配置指纹；处理时重新校验，配置变更或停用后不使用其他配置代替。
- 移除 ASSISTANT_ALLOWED_HOSTS 必填限制，保留 HTTPS、公网地址校验、DNS 固定和禁止重定向。
- 复用 TEACHER_SYNC_ENCRYPTION_KEY 加密，不更换现有值。MESSAGE_WS_LISTEN 保持内部监听用途。
- 自助绑定：教务档案有手机号时短信验证；确实无手机号时验证学号、姓名、完整身份证号。验证码失败不能降级到身份证验证。无两类资料时需管理员补齐。

## 文件边界

- `server/app/model/channel/AssistantProfile.php`：个人配置查询及结构升级。
- `server/app/server/message/AssistantConfiguration.php`：两类配置读取、授权、加密、指纹。
- `AssistantRecord.php`：会话和轮次来源持久化，所有 SQL 在模型内。
- `AssistantService.php` / `AssistantAnswerConsumer.php`：提交与消费共用配置解析。
- `fontend/shared/components/AssistantPanel.vue`：两端共用操作界面。
- `server/database/updates/20260920-assistant-personal.sql`：管理员单独执行的结构升级。

## 数据约束

旧会话和轮次按 school 处理；旧排队任务缺少配置指纹时失败并提示重新发送，避免升级期间误用新配置。个人密钥不进入日志、队列消息和前端响应。每个请求继续使用唯一 request_id，保持防重复提交与频率限制。
