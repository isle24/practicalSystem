# 基础档案设计

## 1. 概述

基础档案是系统的数据底座，为实习、实训、实验三大业务模块提供组织架构和人员数据支撑。档案管理归属于超级管理员和学校管理员。

表名和核心字段与论文系统保持一致：`department`、`grade_list`、`profession`、`class`。其中 `grade_list` 在本系统中表示入学年级，是学院、专业、班级之上的最高级筛选维度；`graduation_cohort` 独立表示毕业届次，只用于毕业实习等按毕业届次组织的业务。学生和教师档案见 `02-用户服务设计.md`，实习基地档案见 `08-实习管理模块设计.md`。

## 2. 数据模型

> 所有表位于所属学校数据库中，无需 school_id 字段。统一包含 `created_at`、`updated_at`、`deleted_at`，支持软删除。

### 2.1 department（院系）

对应论文系统 `department` 表，去除论文特有字段（ass_id、bss_id、council、leader、paper_title_type、default_show）。

```
department
  - dep_id（PK，自增）
  - uuid（对外唯一标识）
  - dep_name（名称）
  - full_dep_name（全称）
  - dep_introduction（简介，TEXT）
  - flag: on / off（是否启用，默认 on）
  - remark（备注，TEXT）
  - sort（排序，默认 0）
  - created_at, updated_at, deleted_at
```

### 2.2 grade_list（年级）

对应论文系统 `grade_list` 表，去除论文特有字段（guide_number、grade_teacher）。本系统按入学年级使用，不归属于学院；教师指导容量由 `grade_teacher_guide` 表管理（见 02-用户服务设计.md）。

```
grade_list
  - grade_id（PK，自增）
  - grade_uuid（对外唯一标识）
  - grade_name（年级名称，如 "2026级"）
  - flag: on / off（是否启用，默认 on）
  - sort（排序，默认 0）
  - is_current: false / true（是否当前年级，默认 false）
  - created_at, updated_at, deleted_at
```

### 2.3 graduation_cohort（毕业届次）

毕业届次与年级独立维护，用于毕业实习计划及学生毕业归属，不参与实验实训和其他实习的年级筛选。

```
graduation_cohort
  - cohort_id（PK，自增）
  - cohort_uuid（对外唯一标识）
  - cohort_name（毕业届次名称，如 "2030届"）
  - cohort_year（毕业年份）
  - flag: on / off（是否启用，默认 on）
  - sort（排序，默认 0）
  - is_current: false / true（是否当前毕业届次，默认 false）
  - created_at, updated_at, deleted_at
```

### 2.4 profession（专业）

对应论文系统 `profession` 表。

```
profession
  - profession_id（PK，自增）
  - uuid（对外唯一标识）
  - profession_name（专业名称）
  - school_profession_code（校内专业代码）
  - full_profession_name（专业全称）
  - profession_remark（备注，TEXT）
  - dep_id（所属院系，关联 department.dep_id）
  - education（学历层次：专科/本科/研究生）
  - flag: on / off（是否启用，默认 on）
  - grade_id（所属年级，关联 grade_list.grade_id）
  - created_at, updated_at, deleted_at
```

### 2.5 profession_direction（专业方向）

```
profession_direction
  - direction_id（PK，自增）
  - uuid（对外唯一标识）
  - profession_id（所属专业，关联 profession.profession_id）
  - direction_name（方向名称）
  - direction_code（方向代码，可为空）
  - flag: on / off（是否启用，默认 on）
  - remark（备注，TEXT）
  - created_at, updated_at, deleted_at
```

### 2.6 class（班级）

对应论文系统 `class` 表。

```
class
  - class_id（PK，自增）
  - uuid（对外唯一标识）
  - class_name（班级名称）
  - grade_id（年级，关联 grade_list.grade_id）
  - dep_id（所属院系，关联 department.dep_id）
  - profession_id（专业，关联 profession.profession_id）
  - profession_direction_id（专业方向，可选）
  - flag: on / off（是否启用，默认 on）
  - remark（备注，TEXT）
  - created_at, updated_at, deleted_at
```

### 2.7 companies（基地/合作单位）

基地/合作单位表为实践管理系统特有，论文系统无此表。PC 端统一展示为“基地管理”，可维护实习基地、合作单位及企业侧联系人信息。

```
companies
  - company_id（PK，自增）
  - uuid（对外唯一标识）
  - company_name（基地或合作单位全称）
  - company_code（统一社会信用代码，唯一）
  - company_short_name（基地或合作单位简称）
  - company_type: state_owned / private / foreign / joint_venture / public_institution / other
  - company_address（地址）
  - company_contact（联系人）
  - company_phone（联系电话）
  - company_email（联系邮箱）
  - company_scale: small / medium / large
  - company_industry（所属行业）
  - flag: on / off（是否启用，默认 on）
  - created_at, updated_at, deleted_at
```

## 3. 实体关系

```
department (院系)
  ├── 1:N → profession (专业)
  ├── 1:N → class (班级，冗余)
  ├── 1:N → students (学生，通过 dep_id 关联)
  └── 1:N → teacher_list (教师，通过 dep_id 关联)

grade_list (年级)
  ├── 1:N → profession (专业)
  ├── 1:N → class (班级)
  ├── 1:N → students (学生)
  ├── 1:N → practice_* (实验实训业务)
  └── 1:N → internship_plan (非毕业实习计划)

graduation_cohort (毕业届次)
  ├── 1:N → students (学生毕业归属)
  └── 1:N → internship_plan (毕业实习计划)

profession (专业)
  ├── 1:N → profession_direction (专业方向)
  └── 1:N → class (班级)

companies (基地/合作单位)
  └── 1:N → base (实习基地，见 08-实习管理模块设计.md)
```

## 4. 档案与用户体系的关系

档案表（students / teacher_list）通过 `user_id` 挂载到用户体系（users），但组织归属（dep_id / profession_id / class_id / grade_id）和学生毕业归属（graduation_cohort_id）由档案表自身管理。详见 `02-用户服务设计.md` 第 1 节。

## 5. 数据导入

基础档案支持以下导入方式：

- 超级管理员/学校管理员 PC 端手动录入（单条新增/编辑）
- Excel 批量导入（模板下载 → 填写 → 上传 → 校验 → 入库）
- 教务系统同步（通过 EduAdapter 拉取，见 `02-用户服务设计.md` 第 8 节）

导入去重规则：

| 档案 | 去重字段 |
|---|---|
| department | dep_name |
| grade_list | grade_name |
| graduation_cohort | cohort_name，存在 cohort_year 时校验年份一致性 |
| profession | dep_id + grade_id + profession_name，存在 school_profession_code 时优先使用 school_profession_code |
| profession_direction | profession_id + direction_name |
| class | grade_id + profession_id + class_name |
| companies | company_code |

## 6. 管理界面（PC 端）

- 学院管理：列表，增删改查
- 年级管理：列表，增删改查，维护是否当前年级
- 毕业届次管理：列表，增删改查，维护是否当前毕业届次
- 专业管理：列表（按年级/学院筛选），增删改查
- 班级管理：列表（按年级/学院/专业筛选），增删改查
- 基地管理：列表（按类型/行业筛选），增删改查
- 全部支持 Excel 导入导出
