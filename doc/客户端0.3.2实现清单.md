# 客户端 0.3.2

- 修正 Mac 风格窗口控制图标居中。
- PC/H5 共用文件预览：图片、音视频、PDF、DOCX、XLSX；旧版 DOC/XLS 保留下载。
- 复用文件权限，不向第三方文档服务传输文件；解析库按需加载，限制预览体积和表格行列。
- 收藏链接支持共享的非敏感 Query/POST 参数；个人 Header/Cookie/POST 凭据仅保存到客户端系统凭据库。
- 原生认证交换只允许 HTTPS、目标同源，不跨域转发凭据，不提供任意站点登录绕过。
- 普通浏览器不注入 Header/Cookie；客户端凭据按学校、账号、收藏和目标地址隔离。
- 编译 PC/H5 并提交服务端静态文件；GitHub 仅同步客户端需要的前端源码。
- GitHub Actions 构建 macOS/Windows/Linux 并发布 0.3.2，不在本地生成安装包。
- 客户端缓存默认 8 GB，个人设置可设 0 至 128 GB，0 关闭缓存；清空时仅删除应用缓存目录，不删除服务器原文件。
- 缓存按学校、账号、文件编号及内容摘要寻址；每次读取先验证学校会话及文件权限；缓存不可离线绕过权限。
- Office 文档预览限 30 MB，ZIP 展开声明体积限 100 MB，Excel 独立线程解析并限制可见单元格。完整格式以原文件为准。
- 依赖：PDF.js（Apache-2.0）、docx-preview（Apache-2.0）、ExcelJS（MIT）、fflate（MIT）。PDF 字体、字符映射和解码器随客户端分发。
- 收藏 SQL：`server/database/updates/0.3.2-file-preview-favorites.sql`；本地通过 `DesktopToolsSchema::apply()` 补充字段，不修改已有业务数据。
