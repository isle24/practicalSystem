# H5 原生应用重构实施计划

**目标：** 按 `doc/22-H5原生应用重构设计.md` 将 H5 重构为低冗余、低耦合、高内聚的平台中性业务 App，并统一为接近 iPhone 节奏的交互动效。

**技术栈：** Vue 3、Vite、Vant、Lucide Vue。

## 全局约束

- 后端接口、权限判断、业务状态和业务流程保持不变。
- 不修改 Webman 框架、后端默认路由和 PC 端代码。
- 不引入新的状态管理框架或动效依赖。
- 公共组件只公开视觉、布局和底层交互能力，不包含业务逻辑。
- 不新增测试文件；每阶段通过生产构建和浏览器角色巡检验证。
- 前端生产构建产物写入 `server/public/h5`。
- 每个阶段独立提交。
