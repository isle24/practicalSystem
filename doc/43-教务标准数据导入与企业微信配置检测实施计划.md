# 教务标准数据导入与企业微信配置检测实施计划

**目标：** 在 Webman 项目中实现三种教务 Excel 导入、完整快照与差异确认，同步学生和教师基础档案，并加入企业微信配置检测和“实践系统”默认菜单。

**架构：** 使用独立 `edu` 服务层、源数据表和短期暂存表，由 Redis 队列异步解析，经管理员确认后以事务发布。企业微信配置检测只读调用 `gettoken` 和 `agent/get`，不发布菜单。

**技术栈：** PHP 8.4、Webman 2.1、Laravel Eloquent、PhpSpreadsheet 5.7、Redis 队列、Vue 3、Element Plus。

## 全局约束

- 后端代码位于 `server`，PC 代码位于 `fontend/pc`，H5 不增加导入界面。
- 文档位于 `doc`。
- 只使用 Webman 现有路由、控制器、Service、Model 和队列模式。
- 不创建测试文件，仅执行 PHP 语法、数据库结构、前端构建、接口和实际文件导入验证。
- 学生和教师导入不创建登录账号，企业微信绑定第一次校验成功后再创建。
- 敏感字段不明文存储，不出现在普通列表、操作日志和接口响应中。
- 上传上限为 500MB，具体部署限制需同步 Nginx、PHP 和上游代理。
