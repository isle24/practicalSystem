# 客户端桌面自由定位与风格

## 已确认范围

- 桌面图标使用自由像素坐标，允许空白；启动台继续使用网格排序。
- 坐标按服务端地址和账号保存到本机，不写数据库。切换风格不改变快捷方式集合。
- 拖动不触发打开；图标不能落到任务栏外；缩小窗口仅调整显示位置，不覆盖原布局。
- 桌面右键提供恢复默认布局，需要二次确认。存储不可用时提示。
- Windows 使用贯穿底部任务栏、居中启动入口及搜索、右侧系统状态。
- Mac 使用磨砂悬浮 Dock、独立启动台、左侧红黄绿业务窗口按钮。保留个人设置、身份切换及退出入口，不添加顶部栏。
- 共用组件及业务逻辑，不修改服务端流程和数据库。系统原生窗口装饰不伪造。
- 完整代码及 PC 编译产物提交 Gitea；公开 GitHub main 仅更新前端及打包内容，不推送后端历史。
- 安装包只由 GitHub Actions 构建，全部平台完成后发布；不下载到本机。

## 实施顺序

- [x] 定位：新增 useDesktopPositions，处理坐标校验、边界、拖拽、取消和本地保存；AdaptiveDesktopGrid 接入，App 接入账号键和恢复操作。
- [x] 风格：DesktopWindow 添加模式属性，复用控制按钮；独立 desktop-appearance.css 定义 Windows/Mac 外观及窄屏约束。
- [x] 验证：编译 PC 和客户端前端，检查 Rust；实际浏览器验证拖拽、刷新、恢复、风格及窗口缩放，不新增验证文件。
- [ ] 发布：维护版本与说明，提交并推送 Gitea；隔离同步 GitHub 前端 main，触发云端构建并确认发布状态。

## 异常处理

- 无效缓存忽略；账号切换中取消拖动，不能写入其他账号的坐标。
- 拖动超出桌面夹紧边界；与其他图标重叠时寻找临近空位。视口缩小后按可用空间展示。
- 取消指针、窗口失焦或按 Escape 时还原；拖动只在释放后保存。
- GitHub 历史 master 仍包含后端，此次不删除分支或标签，不向其推送。
