# 桌面工具实施清单

已获用户确认，在当前任务逐步执行，不派子智能体。后端 PHP 8.4/Webman，前端 Vue 3，桌面 Tauri 2/Rust。

- [x] 共享收藏：新增 `FavoriteRecord`、`FavoriteService`，扩展 `favorite_link`；统一可见性、文件引用、桌面查询和保存结果。PC 提取 `FavoritePanel`。
- [x] 个人记事本：新增 `NoteRecord`、`NoteService`、`NoteController`、`user_note`，实现账号隔离、修订号、回收站；PC/H5 复用 Markdown 编辑组件。
- [x] 版本后台：新增版本、SQL 和安装包 Model/Service/Controller，草稿与已发布快照分离；SQL 仅管理员查看和人工登记，日志隐藏笔记正文及 SQL。
- [x] 外部窗口实现：Rust 独立窗口、链接模式和原生菜单；外部网页不得获得学校上下文或 IPC。
- [x] 更新管道实现：学校 Redis 下载 GitHub 包、哈希/平台校验、文件引用、手动发布；客户端官方 updater 验证签名、显示进度、保存确认和覆盖安装。
- [x] 构建配置：Actions 构建 Mac 通用、Windows 和 Linux，统一签名与发布；服务端 SQL 单列。
- [ ] 原生交付核验：签名 Secrets 配置后运行三平台构建与 GitHub Release；检查实际安装和更新行为。
- [ ] 学校发布联调：配置仓库只读令牌后导入安装包，由学校管理员确认后发布。

各项完成后执行 PHP 语法、前端编译及 Rust 格式/静态检查，并核对实际接口和页面行为。不新增自动化用例或相关文件。沿用默认路由，不修改框架和 vendor。

共享状态采用 `scope=personal|school`、`open_mode=client|browser`；保存返回 `item`，所有列表同时提供 `pagination`。个人笔记用 `revision` 防止多窗口覆盖，所有变更根据登录账号重新校验归属。

本地学校数据库编号 1 已执行增量结构升级；PHP 语法、PC/H5 和客户端前端编译通过，Rust 检查通过。已核验六类角色的接口权限、笔记归属和修订冲突、共享收藏撤回，以及发布快照隔离。PC 收藏和版本弹窗已检查；H5 窄屏入口已检查，后续编辑导航的完整交互仍需复核。未保存的草稿改为页内提示恢复，避免打开页面时弹原生确认框。

GitHub 签名 Secret 写入接口返回 403，当前 Secrets 列表为空；未发布 0.2.0 安装包。服务端尚未配置 `DESKTOP_GITHUB_TOKEN`，不使用开发者高权限凭据代替部署令牌。

服务端版本清单只导入草稿。安装包下载通过 Redis 队列执行，发布操作只修改已经完成的版本；普通用户接口不返回 SQL、草稿或技术凭据。GitHub 发布安装包不等于在学校发布更新。
