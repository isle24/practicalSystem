# 客户端扩展设计

## 范围

本次版本包含客户端本地菜单排序、学校连接账号管理、日志中心展示、消息中心会话化展示和受控 Web 插件目录。客户端登录协议、学校业务权限和现有业务接口保持不变。

## 客户端本地数据

菜单排序、桌面快捷方式、最近连接和客户端外观属于设备偏好，按学校域名与登录账号隔离保存。普通偏好使用客户端本地存储；域名和账号可以写入连接配置，密码只通过 Tauri 原生命令写入系统凭据库。浏览器端不保存密码。

## 日志与消息

日志中心复用操作日志接口，优先展示业务动作、模块、操作者、时间和结果，接口路径作为辅助信息。消息中心复用 `message` 和 `message_target`，在现有按时间消息列表上增加会话分组、未读标识和关联页面入口。实时推送仍由后续 WebSocket 通道扩展，当前版本保证 HTTP 分页可用。

## 插件目录

插件目录只允许服务端维护的 Web 入口，插件声明名称、版本、图标、入口地址、允许打开方式和权限说明。第一版不执行任意原生代码，不把网盘账号密码交给本系统；网盘入口使用官方 OAuth 页面或外部浏览器打开。

## 失败处理

本地凭据读写失败时仍允许手动连接；远程接口失败时保留本地菜单和连接列表；插件入口校验失败时禁止打开；消息和日志查询失败时保留错误提示和重试入口。
