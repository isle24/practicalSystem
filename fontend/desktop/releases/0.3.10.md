# 实践管理系统客户端 v0.3.10

- 组织范围账号选择改为远程搜索，每次最多 50 项，支持已选账号回显。
- 菜单按实际打开或切换加载；移动、调整大小和聚焦窗口不再重复读取数据，恢复文件、日志和统计窗口保留页码。
- 管理基础选项与实验实训选项按账号和权限缓存，合并并发请求；快速切换统计和实训筛选时忽略过期响应。
- 用户、班级、专业、企业、任务及计划等下拉使用虚拟列表，学生分配和导入预览分页显示，保存保留完整数据。
- 修复教师打开教案编写时新增按钮引用未定义变量导致的渲染异常。
- 审批流程版本批量读取，实习统计使用索引减少重复扫描，保留原统计口径与权限范围。

服务端及编译后的 PC 资源需同步部署并重启 Webman。本版本无新增 SQL；尚未执行 0.3.9 文件索引迁移的学校仍需按该版本说明升级。系统更新 JSON 与客户端版本均为 0.3.10。
