# 实践系统客户端 v0.3.17

- 首次连接默认地址为 `https://sxxt.cdjcc.edu.cn`，默认学校名称为“成都锦城学院”。
- 登录后直接进入桌面，不再自动打开数据管理。
- 客户端支持企业微信扫码登录；只有一个有效绑定账号时自动登录，多个账号仍由用户选择。
- 优化手机企业微信扫码确认页面及 H5 绑定二维码入口，统一深色主题并修正专业、班级筛选遮挡。
- 客户端顶部栏默认隐藏，顶部悬停显示；原生全屏时任务栏和 Dock 底部悬停显示，非全屏常驻。
- 走访安排新增立项年份，本校超级管理员可删除其他管理员填写的走访记录。
- 学院管理员支持按学院或指定多个账号共享收藏，符合条件的账号桌面自动显示入口。
- 实习系统提供第三方 OIDC 授权和客户端一次性会话转接；首次在目标系统本人登录后绑定，论文系统实际接入另行进行。
