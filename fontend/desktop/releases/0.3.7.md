# 实践管理系统客户端 v0.3.7

## 学校设置与个人设置

- 学校管理员可上传学校 Logo，替换登录页学校名称旁的默认图标。
- 学校外观设置与个人设置分开；学校壁纸、默认壁纸由管理员维护。
- 增加共享壁纸库。个人上传壁纸默认私有，可单独开启分享；用户可应用共享壁纸或自己上传过的壁纸。
- 个人设置增加电子签名，可在 H5 手写，或扫码在手机端完成签名。

## 审批与经费

- 增加基地申报审批和基地建设费用申请工作流，支持可配置审批节点、待办、阶段通知、签名和意见记录。
- 增加经费管理，支持建设费用明细、附件、合计及审批过程 Word/PDF 导出。
- 实习、实验实训、社会实践继续使用原审批规则；既有审批不迁移。
- PC 客户端增加扫码绑定企业微信入口。

## 实习基地与窗口

- 基地建设增加立项状态；实习基地菜单调整为基地申报、基地汇总统计、审批表和基地巡查。
- 实习计划支持软删除，可选择一并删除关联实习任务；相关历史数据保留。
- 最大化窗口和弹窗时隐藏桌面 Dock；修正登录页客户端下载按钮的 Hover 样式。

## 服务端升级

先更新服务端代码和依赖，在“系统配置 → 数据库结构”生成并审核学校数据库升级 SQL，再由维护人员执行并复核。此次结构升级包含学校外观、壁纸、企业微信扫码绑定、签名、工作流、经费明细及基地立项字段。升级后重启 Webman HTTP、队列和消息投递进程，再导入并发布客户端 0.3.7。

实习、实验实训、社会实践原有审批数据与规则保持不变；本次不自动迁移旧流程。
