# 实践系统客户端 v0.3.43

- 新增教学计划中心：按专业学院全称或简称分配权限，人工分类到实习、社会实践、实验或实训，保留导入原始字段和差异记录。
- 首次补齐缺少的业务资料后免审生成；生成后的修改和再次导入差异须审核，不能覆盖已生效计划。
- 实习、实验、实训计划支持统一审批流程配置；未配置时继续原审核，保留进行中流程快照、签名和版本校验。
- 社会实践计划发布暂不发送通知；新增项目提前检查计划资格，不可选项显示原因。消息接收人分批写入，修复批量占位符超限。
- 补齐表单必填、选填、提交时必填标识，展示菜单操作步骤和下一步；修正课节错误提示、归档检查错位和关联字段校验。
- Agent 内置项目 Skill 与操作指南同步更新；外部 CLI/Skill 版本为 0.2.3。

功能入口由学校服务端和账号权限决定。教学计划中心完整补齐表单使用 PC 或桌面客户端。
