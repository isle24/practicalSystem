# 实践管理系统客户端 v0.3.8

## 账号与登录

- 角色编辑按目标角色显示并保存学院、专业组织范围，服务端校验管理员组织归属。
- 个人设置支持双方验证后建立、解除和切换关联账号。
- 消息发送默认不包含发送者，可按需发送一份给自己，收件人预览与实际名单一致。
- 增加已绑定企业微信账号的扫码登录，未绑定账号提示先完成绑定。
- 客户端启动完成连接和会话初始化后再显示登录页，避免网页登录框闪现。

## 桌面外观与窗口

- 头像、在线状态、下载、切换账号、退出和时间移动到顶部标题栏，最大化时保留入口。
- 增加亮色、暗色和跟随系统的本地主题，支持预置主题及本地壁纸、颜色、透明度和密度配置。
- 桌面模块文字改为白色并增加阴影，提高不同壁纸下的可读性。
- 收藏和插件支持在客户端当前页打开受限外链。

## 凭据与发布

- 本机凭据增加索引、单条删除和清空能力，收藏改址或删除时清理历史凭据。
- 增加默认关闭的云同步开关，服务端使用 AES-256-GCM 加密保险库存储同步凭据。
- 客户端图标沿用跨平台图标包资源。

服务端数据库结构升级和企业微信 OAuth、云凭据密钥配置需由部署人员按服务端发布流程完成后再启用对应功能。
