# 实践系统客户端 v0.3.18

- 首次连接默认地址为 `https://sxxt.cdjcc.edu.cn`，默认学校名称为“成都锦城学院”。
- 连接页与 PC 网页共用右上角扫码/密码切换按钮，点击切换登录方式，不显示登录方式 Tab；已填写学校地址时，扫码入口直接连接并显示二维码。
- 登录后直接进入桌面，不再自动打开数据管理。
- 客户端支持企业微信扫码登录；只有一个有效绑定账号时自动登录，多个账号仍由用户选择。
- 优化手机企业微信扫码确认页面及 H5 绑定二维码入口，统一深色主题并修正专业、班级筛选遮挡。
- 客户端顶部栏默认隐藏，顶部悬停显示；原生全屏时任务栏和 Dock 底部悬停显示，非全屏常驻。
- 走访安排新增立项年份，本校超级管理员可删除其他管理员填写的走访记录。
- 学院管理员支持按学院或指定多个账号共享收藏，符合条件的账号桌面自动显示入口。
- 实习系统提供第三方 OIDC 授权和客户端一次性会话转接；首次在目标系统本人登录后绑定，论文系统实际接入另行进行。

服务端及 PC/H5 资源需同步更新并重启 Webman。已完成 0.3.13 及此前结构升级的学校，在当前学校库执行本版附带的 `20261012-sso-authorization.sql` 和 `20261012-desktop-visits-favorites.sql`，或依次运行 `php database/migrations/20261010_sso.php 学校数据库编号`、`php database/migrations/20261012_desktop_visits_favorites.php 学校数据库编号`。复核结构并登记 SQL 处理结果后，由学校管理员发布系统更新及客户端更新。

安装客户端不会部署学校后端。第三方应用须完成注册、签名发行方配置及目标端协议接入后才能授权登录，不使用旧 passlogin 令牌替代新协议校验。
