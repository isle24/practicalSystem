# 实践系统客户端 v0.3.20

- 客户端使用锦城教务图标。
- 账号密码在客户端登录页直接校验，错误原页提示，可修改后重新登录。连续第三次密码错误后显示验证码，成功后直接进入桌面；记住密码仅在登录成功后保存。
- 新增手动锁定和闲置自动锁定，默认 30 分钟，时长在本机设置。支持密码或已绑定企业微信扫码解锁，保留当前工作状态。
- 登录页增加找回密码，可通过本人已绑定的企业微信扫码设置新密码。
- 文件预览可选择本地 Office 打开，或将 Word 文档在本机转换为 PDF 后预览；设置和转换缓存保存在本机。Windows 优先使用 Microsoft Word，LibreOffice 备用；macOS/Linux 使用已安装的 LibreOffice。
- 桌面模块的编辑入口保留在右键菜单中，隐藏图标上的直接编辑按钮；仍遵守原有编辑权限。
- 用户管理增加企业微信绑定状态筛选。教师可按学院查询，学生可按学院、专业和班级查询。
- 修正明暗主题颜色、筛选控件遮挡和部分界面状态问题，完善设备下线、锁屏与账号切换后的会话隔离。
- 更新提示只展示功能和使用变化。
