# 实践管理系统客户端 v0.3.3

- 修复 TXT 无法内置预览，补充 LOG、JSON、XML、YAML 及常见代码文件的只读预览。
- 文本支持自动编码、UTF-8/GB18030/UTF-16 编码切换、自动换行、行号、分页和搜索定位。
- 新增 Markdown 排版与原文切换，CSV/TSV 表格与原文切换。
- 网页与客户端共用格式清单，新增格式接入默认 8 GB 本机缓存，继续逐次校验权限与文件版本。
- 文本及代码不执行；Markdown 禁止脚本及外部资源，不上传第三方预览服务。
- 文本读取上限 5 MB，展示前 50 万字符；表格最多显示 2000 行、100 列、10 万单元格，完整内容仍可下载。

## 部署注意

无新增 SQL。旧版 DOC/XLS、PPT/PPTX 暂保留下载查看。服务端管理员仍需在版本管理中审核并发布学校内的客户端升级提示。
