# 实践管理系统客户端 v0.3.2

- 修正 Mac 风格关闭、最小化和最大化按钮图标居中。
- 新增内置图片、音频、视频、PDF、DOCX、XLSX 预览，支持图片缩放旋转、PDF 翻页查找和 Excel 工作表切换。
- 文档解析在本机完成，不上传到第三方预览服务；旧 DOC/XLS、复杂文档或不支持的媒体编码保留下载。
- 新增文件预览缓存，默认上限 8 GB。个人设置可修改容量、关闭或清空；按学校和账号隔离，超限自动清理最久未使用的文件。
- 再次预览先校验文件权限和版本，再读取本机缓存，减少重复下载。权限校验仍需要联网。
- 收藏支持非敏感 Query/POST 参数；客户端可为每个收藏配置个人 Header/Cookie/POST 认证参数，保存在系统凭据库，不参与学校共享。
- 认证交换限定 HTTPS 同源入口，需目标系统支持登录协议；不支持验证码或多因素认证绕过，不能代替通用单点登录。

## 部署注意

服务端需同步更新收藏参数接口和数据库结构后再使用新收藏配置。学校管理员仍需在系统版本管理中审核并发布客户端更新。
