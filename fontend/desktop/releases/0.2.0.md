本次更新增加个人记事本、全校共享收藏和客户端版本更新入口。

- 个人记事本支持多篇 Markdown 笔记、即时预览、搜索、回收站和未保存提示。
- 学校管理员可共享常用网址，个人可选择添加至桌面。
- 外部网页可在独立客户端窗口打开，支持原生菜单导航、复制地址和改用系统浏览器。
- 学校管理员发布客户端版本后，客户端提示升级并校验下载签名，安装前确认保存，覆盖安装保留学校连接设置。

v0.1.0 需手动覆盖安装本版一次，之后可使用在线更新。macOS 请将应用拖入“应用程序”后运行。Linux deb 使用系统软件安装器覆盖升级。学校服务须同步更新至支持桌面工具的版本。

安装包包含 Tauri 更新签名。Apple 公证和 Windows 代码签名未配置时，操作系统仍可能显示来源提示。
