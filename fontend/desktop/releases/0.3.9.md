# 实践管理系统客户端 v0.3.9

- 审批流程的人员选择改为远程搜索和虚拟列表，避免全校账号在多个节点中重复渲染。
- 登录页右上角切换账号密码与企业微信扫码；二维码居中显示，保留刷新、状态与账号确认。
- 个人设置改为基本资料、主题与壁纸、账号与安全、消息通知、电子签名、存储与缓存分类。
- 主题增加外观预览卡片，统一设置页表单、间距与深色背景。
- macOS 与 Windows 直接使用提供图标包中的原生 ICNS、ICO。
- 系统更新附带文件存储索引修复 SQL，解决相同图片上传为学校默认壁纸时的旧 MD5 唯一索引冲突。

服务端需一并升级至本次代码；系统更新记录补齐 0.3.8 和 0.3.9。管理员先执行 0.3.9 系统更新中的文件索引 SQL 并登记结果，再发布版本；旧学校库的其他结构沿用现有升级工具。
