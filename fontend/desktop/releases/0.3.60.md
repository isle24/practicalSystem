# 实践系统客户端 v0.3.60

- 下载客户端时默认显示当前电脑系统。选择「其他」查看所有安装包。鸿蒙入口显示「适配中」。
- macOS 提供 Apple 芯片（ARM）、Intel 芯片和通用安装包。打开苹果菜单的「关于本机」核对芯片型号，再选对应的 DMG。
- Windows 64 位电脑使用 EXE 安装程序。Linux 64 位电脑可选适用于 Debian、Ubuntu 的 DEB，或可直接运行的 AppImage。
- 重绘教务菜单图标，优化 Dock「全部应用」的背景和图标叠层。
- Agent 操作在聊天中确认。修复 Windows 调用反馈、macOS 重复钥匙串提示和 Agent 窗口圆角。
- 优化社会实践计划的时间顺序提示和分钟选择。
