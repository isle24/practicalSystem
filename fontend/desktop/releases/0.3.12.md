# 实践管理系统客户端 v0.3.12

- 基地菜单依次为“基地申报、基地审批、基地巡查、基地统计”，保留原菜单编号、权限和地址。
- PC 列表查询、重置靠近左侧筛选条件，新增、导入、导出等操作放在右侧；分页底部显示实际每页条数，单页列表也保留说明。
- 基地可用开关与申报审批状态分别显示；编辑申报时保留已有状态，避免误改审批结果。
- 完善基地和巡查的删除入口、权限与数据范围校验；采用软删除，关联写入保持事务原子性，保留历史记录。
- 统一 PC 列表、分页和操作抽屉的层级、间距及交互状态，修复操作按钮在明暗主题下的对比度。

系统更新文件为 `server/releases/0.3.12.json`。需同步部署服务端和编译后的 PC/H5 资源并重启 Webman；仅安装客户端不会更新学校服务端逻辑。

已完成此前学校结构升级的学校，执行本版本附带的 `server/database/updates/20261008-base-menu-order.sql`，或在 `server` 目录运行 `php database/migrations/20261008_base_menu_order.php 学校数据库编号`。两种方式均只更新既有菜单名称和排序，可重复执行，不改变角色授权、业务数据或表结构。完成后登记 SQL 执行结果，再按“版本与更新”流程发布系统及客户端 0.3.12。
