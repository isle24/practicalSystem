# 实践管理系统客户端 v0.3.1

- 桌面支持自由像素拖动定位，允许留空，按学校及账号保存在本机；启动台保留网格排序。
- 桌面右键可恢复默认布局；拖动支持边界限制、重叠避让及 Escape 取消，缩小窗口不覆盖原始坐标。
- Windows 风格使用居中搜索与底部任务栏；Mac 风格提供悬浮磨砂 Dock、运行指示点及左侧红黄绿业务窗口按钮。
- 两种风格共用桌面快捷方式，修复 Mac 桌面显示全部模块、搜索结果裁剪和图标对比度问题。
- 连接页支持账号密码登录、多账号连接记录、记住密码及自动登录；密码保存在系统凭据库。
- 切换学校或账号时清空旧密码输入，重新连接前提醒保存当前内容。
- 日志审计增加操作名称、请求结果、参数及设备详情。
- 消息中心采用左侧分类、右侧时间流的布局。
- 插件中心支持维护 HTTPS Web 入口、搜索及分页；管理员可管理停用入口，普通用户仅可打开启用入口。
- 修复最近连接异步读取、排序保存后未立即刷新、未配置自动登录时错误提示等问题。
