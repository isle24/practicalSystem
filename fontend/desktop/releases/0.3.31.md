# 实践系统客户端 v0.3.31

- Agent 提供独立入口与聊天、模型、插件、记忆、定时任务、提醒和状态页面。
- 输入模型基础地址和密钥后，可由本机获取模型列表、检查连接；支持可信内网地址与自定义端口，聊天过程中可切换模型并保留文本上下文。
- 个人提供方配置云端加密同步，PC/H5 助手配置保持独立；会话、记忆和插件设置只加密保存在本机。
- 内置系统 Skill，支持导入文本 Skill 包和配置 MCP 服务，MCP 工具执行前由原生窗口确认。
- 本机任务在客户端运行且解锁时执行，关闭或休眠期间错过的任务由用户决定是否补跑。
- 修正 macOS 切回应用时主窗口遮住 Agent，以及最小化后打开 Agent 无法恢复的问题。
