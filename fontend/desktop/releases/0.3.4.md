# 实践管理系统客户端 v0.3.4

- 连接页去除图标，已连接学校显示学校名称与本机备注，支持切换学校和历史账号。
- 消息中心接入 WebSocket 刷新、心跳与断线补取，继续使用原有消息和待办权限。
- 增加个人问答助手。学校尚未配置接口时保持停用，不读取业务档案、不执行审核或数据修改。
- 教务导入详情按字段显示原值、新值，支持分页和折叠查看。
- 网页版提供客户端下载入口；管理员支持安装包分片上传，以及已就绪平台先发布、其他平台继续后台下载。

## 服务端升级

必须先升级学校服务端并执行对应版本的学校库更新 SQL，再重启 Webman。消息通道需要 NGINX 转发 `/ws/messages`，详细配置见服务端部署文档。

问答接口、模型和密钥由学校管理员稍后配置。此版本不包含教务账号批量创建，也不改变学生先绑定再登录的规则。GitHub 下载不等于学校内发布，管理员仍需确认发布后才向用户提示升级。
