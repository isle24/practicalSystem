# 实践管理系统客户端 v0.3.6

## 企业微信与通知

- 用户管理显示企业微信绑定状态，可查看绑定详情，学校管理员可解除绑定。
- 教师、学生在企业微信内登录已有系统账号后，未绑定时须确认绑定；管理员可跳过。
- 消息中心和消息模板可勾选企业微信渠道，绑定并开启通知后接收推送。
- 个人设置支持通知接收时段，默认全天；时段外的企业微信通知顺延至下一个允许时间。
- 企业微信设置增加“立即同步菜单”，完善接收消息回调及配置校验。

## 基地巡查

- 管理员指定基地和负责教师，教师填写走访日期、上午或下午、开始及结束时间。
- 同校同日同半天的其他安排会提示重复，仍允许保存。
- 走访后录入实际时间、参加人员、接待人员、走访内容、问题、后续措施和附件。
- PC“基地管理 → 基地巡查”和教师独立入口可使用；手机端从“首页 → 常用服务 → 基地走访”进入。

## 数据管理与界面修复

- 系统配置增加数据库结构检查，对比表、字段和索引，支持差异查看、升级 SQL 预览和下载。
- 完善学生档案导入入口，学年、学期改为下拉筛选，学生和课程列表分别展示。
- 增加基地导入模板，完善管理员数据清理任务与进度查看。
- 修复侧栏选中状态、筛选控件错位和长菜单无法滚动的问题。
- 修复二级模块桌面快捷方式恢复、桌面拖动和表格预览显示问题。

## 服务端升级

先更新学校服务端及依赖，在“系统配置 → 数据库结构”执行完整比对，生成并审核升级 SQL，由维护人员执行后重新检查。此次涉及企业微信通知字段、数据清理任务表、基地走访安排及记录表；结构检查不会自动执行 SQL。

完成升级后重启 Webman HTTP、队列和企业微信消息分发进程，再由学校管理员导入并发布客户端 0.3.6。服务端更新说明同步提供 PC、H5 可见内容。

学生档案导入不会自动开通登录账号；企业微信绑定仍以已有系统账号为前提。
