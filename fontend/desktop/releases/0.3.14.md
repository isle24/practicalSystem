# 实践管理系统客户端 v0.3.14

- PC Web 与客户端数据列表支持拖动表头分隔线调整列宽。
- 列宽仅保存在当前设备本地，按学校、账号、角色和列表区分；刷新、重新打开和字段切换后恢复，不发送列宽保存请求。
- 经费列表、经费明细和分组成绩记载表接入统一列宽能力，保留原操作、勾选、打印及导出。
- 表格边框和拖动线使用统一主题颜色。

本版无新增数据库 SQL，升级清单为 `server/releases/0.3.14.json`。部署新版 PC 资源并安装客户端 0.3.14 即可使用列宽功能。

尚未完成 0.3.13 升级的学校，仍需按该版本清单执行走访记录和基地课程库升级 SQL，并登记处理结果。
