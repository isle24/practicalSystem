# 实践管理系统客户端 v0.3.13

- 新增独立走访记录菜单，支持直接新增、查看和修改；学院管理员填写，学校和系统管理员可代填修正，教师仅查看参与记录。
- 基地立项使用开关，地址支持省市区三级联动和详细地址，服务课程从可维护课程库选择，负责人支持姓名及单位搜索。
- 走访联系人和主管院长统一显示姓名、单位，不显示工号；基地巡查移除基地学院展示。
- 修正客户端抽屉和最大化弹窗被标题栏遮挡的问题，恢复适用列表的筛选展开、隐藏入口，统一明暗主题样式。
- 个人菜单集中显示个人姓名、在线状态、客户端版本、身份切换和退出。

服务端升级清单为 `server/releases/0.3.13.json`。在目标学校库直接执行附带的 `server/database/updates/20261009-base-visit-and-catalog.sql`，或使用数据库结构比对生成的 SQL。两种方式均包含结构、历史记录回填及菜单授权，无需单独执行 PHP 迁移。

部署服务端与 PC/H5 资源、重启 Webman，执行 SQL 并登记处理结果后，再按学校“版本与更新”流程发布系统和客户端更新。
