# 实践系统客户端 v0.3.19

- 底部 Dock 在模块最大化时自动隐藏，无需客户端进入 F11 全屏；悬停底部或键盘聚焦时显示，恢复、最小化或关闭最大化模块后常驻。
- 顶部状态栏采用跟随明暗主题的半透明玻璃背景，默认常驻。
- 个人设置新增顶部状态栏和底部 Dock 两个自动隐藏开关。关闭对应开关后常驻，只保存在当前设备，不上传服务器。
- 个人头像菜单提供“切换账号”，存在其他可用账号时显示，沿用本人和已绑定账号的权限规则。
- 桌面图标右键可修改打开方式，按学校及账号在本机保存；独立窗口直接加载所选模块，避免重复开窗。
- 收藏所有者及具有编辑权限的管理员可直接点击图标编辑按钮；菜单管理员可直接进入对应菜单编辑界面。

本版无新增数据库结构或 SQL。学校 PC 网页需同步部署本版 PC 资源；客户端内置本版桌面资源。服务器仍需具备 0.3.18 对应的接口与数据库结构，第三方授权及论文系统接入沿用上一版要求。
