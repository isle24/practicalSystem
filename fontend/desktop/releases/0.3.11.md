# 实践管理系统客户端 v0.3.11

- 修复已登录学校账号打开收藏外部应用时，错误提示“请先登录有效学校账号”的问题；凭据库从受保护接口读取完整身份，并校验用户和账号一致。
- 收藏与桌面外链增加打开中的状态反馈，同一收藏打开期间重复点击不会重复创建窗口或弹出多次错误。
- 配套 H5 页面优化登录、首页、个人中心和通知列表；统一蓝灰配色、字号间距和触控尺寸，多项筛选支持横向滚动。

系统更新 JSON 为 `server/releases/0.3.11.json`。PC/H5 编译资源需同步部署到学校服务端，H5 更新不依赖安装客户端。本次无新增 SQL；凭据库仍依赖 0.3.8 起的学校数据库迁移。客户端须更新到 0.3.11 才包含原生身份修复。
